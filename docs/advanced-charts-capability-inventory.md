## 2. 需要额外数据或后台的能力

- 自选列表与详情：Trading Platform含右侧列表、多个列表、分组及报价API。当前没有getQuotes/subscribeQuotes及列表存储适配。可沿用M1报价，但应显示其更新口径。
- 成交量相关：volume、成交量蜡烛、固定区间成交量分布等需要相应数据。当前主行情bar映射没有传volume。外汇/黄金不能把tick volume称为全市场真实成交量；BTC也需确认现有采集字段。
- 新闻/事件标记：news_provider、getMarks/getTimescaleMarks是扩展接口，不自带新闻/经济日历订阅。可把自己的策略信号显示为标记，但需要实现数据映射。
- 深度/订单簿：需subscribeDepth及L2数据，M1 OHLC不够。
- 交易终端：经纪商登录、账户/资金、委托/持仓/成交、订单/仓位线、下单改单撤单，需Broker API。与图表多空盈亏比绘图工具是不同功能。
- 图上创建预警：不能把库的按钮/API枚举当作可运行的后台预警服务。必须接market-watch策略、持久化和ntfy。

## 3. 不能从此包直接获得的 TradingView 网站服务

- Pine Editor、Pine Script编译执行和社区脚本市场。
- TradingView用户账户/云布局/付费行情及新闻订阅。
- 网站上的完整Bar Replay。仅找到Replay枚举不足以证明可用回放模块；若需要交互逐根回放，应单列验证和数据控制方案，不能把现有后端演练直接等同于它。
- 筛选器、社区观点、聊天、经济日历、策略测试器等：未确认本包提供可独立接入的完整产品，不作现成功能承诺。

## 4. 推荐二次范围

A（推荐）：完整开放原生图表分析界面，保留图表设置、可用图表类型、全部适用绘图及对象管理、内置+Python指标、模板/收藏、比较叠加、布局同步、原生保存、截图。后台补齐数据/存储/沙箱能力并逐项验收，保留安全隔离。

B（独立确认）：自选列表及详情；建议加入，沿用三品种。

C（需明确数据条件）：全部到8图布局、其他自定义周期、成交量相关图表及指标。

D（单独功能项目）：交互Bar Replay、图上预警/信号标记、新闻日历、下单/深度。

优先完成A+B，C按真实数据条件开放。D按个人需要另外定需求。库本身的默认菜单不再按早期最小工具清单裁剪；功能未就绪时明确说明原因，不把没有接后端的空按钮算完成。
