# 自选控件布局评审

形态来自实际任务：自选主体供扫视行情，控件只在用户要添加、切组或整理时出现。形式应让操作快速完成，视觉重心仍回到走势。

## Form 五问

- 角色：行情主屏之上的短任务操作层。
- 距离：手持手机，近距离阅读与拇指操作。
- 温度：冷静、轻量，沿用产品蓝色。
- 容量：375px 内一列信息；管理页按“品种”和“分组”切换，避免重复清单争空间。
- 母题：真实分组与行情代码组成任务清单，动作随当前目标出现，不加营销式装饰。

## 当前问题（按影响排序）

1. **管理结构重复。** 管理分组大折叠区与品种操作挤在同一滚动页，分组下又展开品种排序，用户难判断当前编辑对象。改为品种/分组两个清晰的任务面，已有保存与放弃语义保留。
2. **尺寸层级不统一。** 操作行 76px、分组行 62px、输入52px、按钮48px；多层边框和单独大块添加分组拉长页面。将普通操作行调至64px，分组选择56px，输入与主按钮48px，小图标操作44px；大字号自然增高，不固定截断。
3. **迁移不完整。** 自选入口、通知/空态按钮、搜索Input、来源按钮、搜索结果操作、分页、详情分组原生select仍混用。逐个迁移并在运行时审计覆盖，不能用“引入过shadcn”替代完成清单。
4. **搜索结果缺少主次。** 每行代码/描述/来源/周期再摆三个分散动作，阅读和点击都绕。信息与添加动作并排，详情/开图为轻量次操作，保持可触区域。
5. **详情页底部操作过长。** 打开图表、选择分组、加入自选纵向堆放，信息区容易被操作区挤占。分组选择在一行，加入与打开以明确主次并排；窄屏大字号可换行。

## 保留

主行情行/曲线空间与配色、既定导航、主题、焦点/返回与未保存保护，以及报价/缓存/冲突逻辑。

## 评审标准

优先功能性、视觉层级与细节执行；不套用海报式大标题或要求手机表单标题是正文的三倍。结论以真实截图与任务操作验证，不用主观总分充当通过依据。
