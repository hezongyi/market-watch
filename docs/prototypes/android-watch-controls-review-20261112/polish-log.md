# 截图打磨记录

延续已认可 A07 / shadcn 方向，使用构建后的真实页面与明确 API 夹具。Python Playwright 不可用，使用项目 Node Playwright 截图；截图不是 Android 系统键盘验收。

## 第一轮

原尺寸查看：管理分组、搜索、详情、主行情，375px 深浅主题。

最伤三处：
1. Tabs 的方向 utility 与实际状态属性未对应，列表与面板挤到一行。显式设置页面 Tabs 的纵向布局，并新增满宽断言。
2. ToggleGroup 的 default 变体继承了主按钮适配，来源项全部变成蓝色。将来源样式限定到 toggle-group-item，采用真实 aria-pressed 判断选中；“全部”的空值改为显示层非空值，提交仍还原为空来源。
3. 组卡展开入口缺少视觉提示、新分组图标触摸区仅40px。恢复展开箭头，提升添加目标到44px。

## 第二轮

查看：改后的品种/分组页签、展开排序、操作菜单、分组列表、搜索和详情选组弹层，含375px/150%字号及深浅主题。

复核与修正：
- 品种与分组各占完整宽度；卡片动作不与展开文字相交，底部提交可滚动可达。
- 搜索添加与辅助动作分层，来源选择保留单选且不能取消全部选择。
- 新增选组交互发现成功通知挂入已关闭菜单；仅标记打开的 Select 为活动弹层，通知监听标记变化，返回只关闭当前选组菜单。

## 最终复核

图表和行情主行不在本次视觉修改范围。检查72px行高、50px图高、左右列和直线渲染；深浅主题、字号和触摸/退场/排序分别验收。最终截图与运行证据见同目录评审报告及 verification 文档。

报告体检：Python Playwright缺失，Node Playwright执行官方COLLECT_JS、Python原函数计算色板/骨架/判定并更新本机账本。修正报告模板连接符与标题字体提示；375/1200px缺图、横向溢出检查均为零。真实Ubuntu只读对照的四组行情几何相等，业务写请求与页面错误均为零。
