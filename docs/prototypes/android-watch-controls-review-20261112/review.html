自选控件布局评审与改造

原问题集中在管理层级重复、控件尺寸偏重、搜索与详情仍混用旧控件。本轮沿用已认可的 A07 与 shadcn 方向：管理拆为品种和分组，统一触摸尺寸，补齐自选完整流程的控件迁移。

2026-11-12，实际构建页面，API夹具截图。评审方法使用 huashu-design；React实现使用项目手机端规范与官方 shadcn Base UI 组件。

调整前后

布局判断

形式来自“扫行情”和“整理自选”两种实际任务：行情保持原空间，整理只在弹层出现；品种与分组分别占一个任务面，分组内排序按需展开。操作行64px、分组选项56px、输入与主按钮48px、图标操作44px，大字号自然增高。
