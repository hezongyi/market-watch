# THROWAWAY — 系统消息工具栏入口三版预览

**当前决策：用户已选定 A 角标型，要求写入方案并暂不实施。B / C 只保留为历史预览。**

用户明确要求先不实现：通知调度方案已确认，入口选择和其他设计确认后一起实施。决策清单见相邻的 `notification-decisions-20261019.md`。

三版在真实专业图表右上角原入口位置做浏览器内临时展示，沿用前一轮系统消息 SVG，使用静态未读数，没有连接点击/阅读/告警确认等业务动作，也没有改动实现分支或验收实例文件。静态预览不需要密码。

- A 角标型：SVG 图标右上角叠加红色数字，52px 固定入口宽度。
- B 并列计数型：SVG 与数字水平并列，76px 固定入口宽度。
- C 文字标签型：SVG、系统消息标签、数字并列，132px 固定入口宽度。

数字仅统计系统消息未读数，交易告警不纳入。每版展示 0、23、128 三种输入：0 隐藏数字，128 显示 99+；可访问名称保留完整数量。每个方案自身的入口宽度在三种数字状态间保持不变，图表画布尺寸不变，页面脚本无错误；见 `browser-proof.json`。
