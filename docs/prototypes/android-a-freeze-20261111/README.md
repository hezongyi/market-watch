# 方案 A · UI 冻结 A06

用户已基本认可 A06，现作为实施的冻结依据；本轮实施方案已按 v2.0.5 收口（仅文档，未开始 App 开发）。A06 五项导航，数据成为一级入口，图表新增十字线与完整指标入口的交互示意；本机自动记忆一份图表设置；各页面保留缓存内容、安静恢复，操作失败与冲突使用浮动通知。仅更新设计预览。

从本目录打开 `index.html` 即可，无构建、网络、后端、数据库或许可库依赖。`?page=watch|chart|alerts|more|center|login` 可直接进入指定页面。底部“设计审阅”仅属于原型，正式产品必须移除。

从仓库根目录一条命令打开：

```bash
python3 -m webbrowser "file://$(pwd)/docs/prototypes/android-a-freeze-20261111/index.html"
```

浏览主链：数据 → 平台/自建/组合 → 详情 → 周期 → 开图；自选 → 管理/分组；图表 → 价格告警 → 保存 → 等待接管；告警 → 详情 → 编辑/归档。表单关闭时可体验“放弃修改”；选择“提交失败/并发冲突”场景后再进入表单提交可看到失败分支。

审阅工具的状态不全部适用于每个页面，例如空列表只作用于自选/告警/数据中心；登录过期直接进入登录。预览密码任意非空，地址只做本地 HTTPS 格式校验，不发出请求。

冻结规范见 `docs/android-ui-freeze-a02-20261111.md`。所有价格、目录支持周期、监控状态为虚构数据；平台/自建/组合示例使用不同 ID，不在开图时偷换系列类型。图表设置通过 IndexedDB 本机记忆，其余演示业务状态刷新重置。审阅“重置”清除图表偏好。专业图表、实际 Android 返回和软键盘、真实 API/ntfy 在实现阶段验证。

网页库沿用 ID `market-watch-android-ui-preview`，只上传 `index.html`、`base.css`、`design.css`、`fixtures.js`、`app.js` 与 `assets/` 下两张已标注出处的官方参考图，不会上传本 README、规范、截图或验证记录。

## A05 当前审阅方式

图表页左上周期下拉，右上指标/告警图标，绘图区填满剩余空间。进入指标应用后自动记忆，刷新可验证；仅这一份图表偏好存入 `mw-android-preview-a05` IndexedDB，不持久化告警/自选/凭据或表单。退出/换服务器/重置清除该偏好。

状态选择：有缓存启动、断网、刷新失败保留内容；部分陈旧仅灰化受影响报价；首次无缓存用骨架、离线无缓存用简短状态。告警、数据中心缓存内容标明“上次”。这些行情快照是固定示例，并未实际采集、持久化或后台刷新；原型断网状态由审阅工具模拟。

选择“提交失败/并发冲突”后提交告警或分组，观察浮窗、输入保留和未保存状态；“恢复”模拟网络恢复，可在保留输入时重试。冲突“查看最新”先保留编辑，明确放弃后才重载。字段格式错误仍就近提示。

专业图表依旧为 SVG 示意；本预览没有 Service Worker、真实离线冷启动壳、网络重连、后端读写、供应商源或 ntfy。正式实施需按最新 UI 规范重新实现业务和验证真机。
