# 稀疏 M1 与已确认日线价格分开判定

OANDA 在已开市区间可能不返回逐分钟柱。2026-10-13 的生产检查发现
EURUSD 日线缺少 M1，但同账户原生 D1 已确认，OHLC 与组合聚合完全一致。
逐分钟覆盖是分钟路径的证据要求，不应自动成为已确认日线收盘价格的拒绝条件。

对收盘模式、完全位于接续段的 OANDA D1，若规则只使用价格、常量或水平线，
允许以同账户、环境、品种、bid、非平滑口径、日界线及区间的原生完整 D1
与组合 OHLC 四值逐项相同，认证该规则的价格依赖。NY17 与 UTC0 各使用明确参数；
不跨拼接点认证，不把分钟缺口改成闭市，不填价格，也不提高成交量完整性。
指标、ATR 偏移、斜线和盘中路径继续遵守各自原有依赖要求。

评估器只登记和读取证据请求；现有 native-history worker 在事务外查询来源，
按账户及区间共享，带有数据库租约、防重复提交和一分钟失败重试间隔。
没有活动规则需求时不发起查询。已确认 OHLC 保存为不可变内容，并引用其校验和
进入判定证据；M1 修订导致 OHLC 不一致时必须重新核对。既有历史版本、组合修订、
日历身份、固定指标结果与判断证据不改写。

当前报价新鲜度与策略依赖就绪分别报告。缺少认证证据为 `coverage_pending`
（判定依赖待核实），断线或实际报价过期仍按原有规则处理。
来源核对恢复后，旧周期、漏失周期与修订周期仍只建立基准，不补发历史穿越。
正常周期仅因等待这份来源认证而短暂挂起时，保留比较状态，在原有新鲜度窗口内
可以判断新穿越，不让每日认证等待反复重置规则。

此替代证据当前仅支持 D1 价格规则。扩展其他周期或指标前，必须定义相应的边界、
数据口径、完整依赖和证据版本，不能统一放宽 `coverage_complete`。
