## 范围与不变量

当前执行范围已按用户后续指示收窄：先分析旧 provider SSE 与主流，再修复主 SSE 已接受尾柱确认的重复 reset。2026-10-14 的 10 分钟生产观测发现 13 次 history_changed；已实现按柱接受确认并在 Ubuntu 受控原生图表验证正常交接零 reset、真实历史修订仍恢复。见 [本轮修复与验证](verification/main-sse-reset-fix-20261014/README.md)。旧 SSE 尚未关闭，未部署生产；下述完整 A1/B、全窗口账本和长期性能门槛仍未宣称完成。本轮实际凭据预算为每消费者 2048 根、每实时批次 128 根，缺失或超预算沿用普通恢复。

正常历史继续 getBars，当前完整柱更新和新柱有序追加继续 subscribeBars。保留 PG 缓存、供源后台预热、native reserve 的提前储备、连续导航、请求优先级、多图联动、稳定指标起点和组合展示快照。绘图工具可见范围保持既有版本。真实 OHLC、时间标签、已供应 volume、插入/删除/缺口更正不能丢弃；生产部署另行授权。

- I1 身份：会话、来源/账户口径、系列/周期及消费者世代隔离；旧结果不提交。
- I2 接受：成功原生回调后提交凭据；SSE 发送只证明传输。实时游标单调，左页仅证明该页范围，不能把其版本推广到全图。
- I3 完整：比较实际 chart_time/Number(OHLC)/合法 volume 投影，范围证明包括首次插入和删除；预算不足为 unknown，不当作相同。
- I4 同版：价格、固定 origin 的递归前缀、指标结果身份一致；异 token 拒收，计算中 pending，不能宣称 ready。确认/告警通路不受展示计算推进。
- I5 更正：同身份视图操作取消旧视窗回写，不取消真实更正责任；切身份才废弃旧责任。
- I6 有界：容量、队列、超时、重试和释放有终局；不能自动丢掉用户已拖出的历史，也不能无限冻结旧画面。

## A0 观测与可重放基线

先保留现有 reset 策略。在 ProviderBar 提交前利用已读取的旧值与最终接受的新值，生成一次供源提交摘要：metadata、OHLC、volume、混合、标签、插入/删除、无变化。仅分类计数、固定幅度分桶和延迟摘要进日志，价格和账户不输出；不把该来源摘要当消费者接受证明。回滚的事务不产生成功摘要，拒收的迟到/未确认回写单独计数。前端后续记录 candidate→复核→reset→回调及 generation 时序。

Ubuntu 控制供源回放包括 15 个 M1 边界，分别同价确认、最终值在新柱前/后到达、volume、混合、首次插入/删除及历史 revalidation；与另一消费者、分页乱序/重叠、拒绝回调、断线/epoch、多图和组合共享路径联合验证。oracle 是时间键接受序列；价格与 Supertrend 对照同一冻结输入完整重算，不读取当前缓存冒充旧版本。

报告分母为源提交/候选/图表小时/M1 接续，多个消费者不重复计算来源修订。报告 unknown 原因、账本命中、volume 幅度与确认延迟。控制回放只证明原因可复现，不能推断生产实际原因比例。

## A1 正常 reset 收敛和必要正确性

先交付有界接受账本及区间凭据，候选按同观察投影复核。metadata 推进凭据，不 reset 主价格；指标依赖状态另行核对。旧尾柱尚为最新时先完整更新再追加新柱；无法等到最终值时及时追加真实新柱，迟到真实差异作为历史更正。重连核对缺口，不能仅因连接变化 reset。

重叠页逐投影验证；过期页拒收，新增左页不倒退实时游标。修复平台非 SWING 双事务：价格窗口和计算前缀在同一个短一致观察中取得，事务外计算，普通增量价格 token 与指标请求/响应/提交闭合。按同版固定 origin 完整前缀重算受影响后缀，保留组合快照选择、规则绑定及 Python 同快照结果。

真实更正使用验证过的普通恢复，允许记录短空白，不能称全面无闪。恢复失败有限重试后明确 error/可重试，不能把原无限重试当正确性终局。

阶段 A 开关由认证服务端能力返回，默认新逻辑关闭至验收；关闭回到 v1.25.3 分类/普通恢复。B 开关独立，关闭回到 A 普通恢复，不用 marketPolling=1。运行中切换取消旧核对/恢复、清理缓冲，以实际接受游标重新注册；四种组合及切换需回归。B 开但 A 关仍用旧分类进入 B，不隐式打开 A。

## B 必要恢复的画面连续性

A 正确性及 unknown 门槛先通过。残余真实更正在目标场景产生空白，即原始目标仍未达成，必须推进 B 原型；修订频率只影响排序，不能决定丢弃真实更正。unknown 过多先修 A。

准备消费者绑定的不可变恢复输入：价格所需全部已加载范围、固定 origin 指标前缀、版本凭据在短 REPEATABLE READ 中冻结，事务外计算。主机种子服务此次 getBars 和指标，不回读当前 ProviderBar。token 绑定会话/身份/消费者/世代/覆盖，过期或无权限明确拒绝；共享输入不共享提交责任。协议 extra=forbid。

ready→preparing→resetting→applying→catching-up→ready，任何阶段有限 error/重试出口。按身份/世代/epoch 排队，合并同柱但保留最早更正/缺口；超限或版本不衔接重新核对。先验证公开画面保留及运行时撤图门槛，不能用两次 RAF、首次 dataReady 或录屏当完成回调。录屏只证明 paint。交互立即撤覆盖、取消旧视窗回写，同身份更正继续；无法证明则保持正确普通恢复并明确无闪未完成。

长历史先按页冻结/共享输入；仍超预算则回到可验证普通恢复并显示未达无闪。如果普通恢复也失败，error 可重试，不能静默截断已加载历史。需要改变容量或历史语义才向用户提出具体选择。

## 预登记门槛与数值

以下为候选实现预算，须记录实际服务端配置和覆盖测试后才能进入 A1/B 验收，不能把文档数字当生效能力。现有历史单源默认 200,000、最大 1,000,000 根，工作区 4,000,000 根，响应 128 MiB；沿用实际配置并核对，禁止另造隐式小窗口。

| 项目 | 初始值与作用域 | 超限终局 |
| --- | --- | --- |
| 接受账本/区间 | 每数据集沿现行历史条数预算；每工作区 128 MiB；最多 512 区间 | 有界复核，仍不足普通恢复 |
| 单次复核 | 20,000 根 / 8 MiB / 10 s；每消费者 1 并发 | unknown reason，普通恢复 |
| B 冻结包 | 每消费者 200,000 根 / 64 MiB，工作区 128 MiB / 2 并发，TTL 60 s | 分页共享评估，仍不足普通恢复，不先 reset |
| 指标输入/响应 | 前缀沿单源历史上限，输出沿历史响应上限，30 s | pending→error，可重试，不提交异版 |
| B 接续队列 | 每消费者 4,096 事件 / 8 MiB | 废弃包重新核对 |
| 准备/恢复/补齐 | 各 30 s，最多 3 次尝试（1/2 s 退避） | error，释放覆盖和包，显式重试 |
| unknown | 未淘汰实时尾受控回放 0；长历史每候选 ≤0.1%，命中 ≥99.9% | no-go；修账本，不用 B 掩盖 |
| 性能 | 同冻结回放同硬件分冷/热/预热 p95 延迟及交互、字节、内存 ≤基线+20%；测量误差 ≤5% | 分层 no-go，不能平均掩盖 |

A1 go：正常 tail/append/metadata 零 reset；真实更正零漏修；分页/世代不丢柱或倒退；Supertrend 所有方向/信号/空值/断点与同输入 oracle 一致；unknown 和性能达门槛。10–15 边界快速验收后至少 4 小时连续运行/回放，含 24x7 与交易时段品种、多图/多参数、周期拖动和断线。休市不生成假 bar。

B go：版本/覆盖/资源闭合，撤图运行条件成立，取消/接续正确且无指标和带 Supertrend 的视频均无清空。固定 licensed v31.1 的资源哈希、补丁身份和浏览器版本，升级重跑 native 合同。负向跨会话/口径/过期 token/注销/旧世代/错误覆盖拒绝。
