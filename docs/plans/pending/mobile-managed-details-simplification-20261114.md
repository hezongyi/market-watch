## 已确认的产品行为

### 品种级历史范围

- 用户只需知道该品种实际已有历史的起止范围，例如 `历史范围 2020/01/01 → 2026/11/14`（示意，非真实数据）。正常层不列各周期的范围、不提示“各周期不同，请查看明细”，也不要求使用者对比不同周期。
- 周期派生、对齐与就绪判断属于内部实现，不转化成新的逐周期选择、阅读或核对任务。已有可用周期摘要可紧凑保留，但不扩充为覆盖表。
- 范围以该品种的基础历史为准。M1/D1 派生使用其实际可用基础历史；原生多周期先核实服务端是否已有统一品种范围语义，必要时在接口内部补齐统一规则，不能让用户选择或比较。不可直接拼接各周期最早起点与最晚终点，不能把维护目标起点、未发布版本或已回收数据当作实际可用历史。
- 统一日期与时区依据，核实区间端点语义，不凭显示需要给所有周期减一分钟。日期级展示不代表区间逐根齐全；末端确需精确到分钟时采用统一格式，不增加每周期细节。
- 尚无历史、生成失败、部分周期未就绪等真实问题保留简短就地状态；已有历史仍可使用时保留实际范围，不用异常信息将其替换。历史覆盖与实时接续保持不同语义。

### 删除数据明细展开

- 删除 `数据明细` 的 Collapsible/DataMore 入口及整段展开内容，不另建技术详情抽屉补回相同复杂度。
- 实际历史范围直接放在主页面历史区；维护规则和参数使用已有“维护设置”；版本信息使用已有固定历史版本入口。实施时核查必要参数在相应入口可读，不承诺尚未核实的展示能力。
- 保留历史/实时两区、必要异常、立即更新、维护设置、固定版本及原有开图能力，不把正常技术字段重新堆入主页面。

### 各特点独立标签

- 品种身份与供应商下方，每个特点是一个独立标签。例如 `M1派生`、`bid`、`NY17` 分别有自己的浅底和轻边界，不能用一个外框包住整串文字，也不再用分隔点串成说明句。
- 固定顺序：生成方式 → 价格口径 → 复权方式 → 日界。仅显示适用且已知的属性，不添加空标签。
- 生成方式：`M1派生` / `D1派生` / `原生周期`；价格口径：`bid` / `ask` / `mid` / `trade`；复权按事实显示“不复权 / 前复权 / 后复权 / 来源价格”；日界为 `NY17` / `UTC0` / `来源交易日`。
- 建议字号 11–12px、高度约22px、间隔约6px；沿用现有主题语义变量，统一中性色、轻边界，深浅主题均可读。具体尺寸以375/412px及150%字号截图确认，不固定高度裁切放大文字。
- 标签仅展示属性，不做按钮，不各自分配鲜艳颜色。宽度不足自然换行，无横向滚动或文本截断。
- 沿用可靠字段映射，不改变持久 mode/basis/adjustment，不将未知口径猜成bid或NY17；NY17仍指纽约当地17点，含夏令时变化，不是固定UTC偏移。

### 加入当前自选

- 删除详情底部“默认自选列表”的分组选择控件，不让用户再次选择目标。
- 加入时读取同一账号/服务器下自选页当前选中分组。当前为“全部自选”或原分组已删除时，沿用首个现存组回落；没有分组时沿用自动创建默认组的行为。
- 当前代码 `ManagedDetails` 的 `group` 初值为空，`addSymbol` 会回落到首组，不等同于当前组；必须修正默认目标，不只删除控件。
- 保留最终防重、偏好冲突保护和失败反馈；不重复加入。“加入自选”与“打开图表”仍是独立动作。

### 自选搜索与添加自建移除上次读取提示

- 自选页打开搜索后，取消 `上次读取 {时间} · 联网后核验` 这条说明，不为其保留空容器或占位高度，不在网络刷新结束时插入／移除同类提示造成控件上下跳动。
- 源码已核实：`web/src/mobile/DataPage.tsx` 的 `SymbolSearchPanel.note` 根据 `result.readAt` 渲染该段文字。
- 后续用户补充确认：添加自建的搜索目录也移除同类提示。对应 `web/src/mobile/DataCatalogSheet.tsx` 中 `result.readAt` 触发的 `离线显示上次目录，联网后核验`，同步移除其容器占位，不以另一条缓存说明替代。
- 保留缓存即时展示、后台重新核验、请求取消、自动分页、搜索语义、已添加排除与提交防重；移除说明不能将旧快照视为刚核实或放松在线写入条件。
- 保留实际读取失败、重试入口及必要的离线不可操作原因；不把本条机械扩大为删除搜索详情或其他页面所有错误提示。添加自建中“部分目录尚未同步”的独立来源状态不是上次读取提示，不因删除缓存说明而顺便删除或冒充目录已同步。
