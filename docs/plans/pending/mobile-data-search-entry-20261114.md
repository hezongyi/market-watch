# 数据页搜索入口轻量化

状态：已随共享搜索实施并通过本地及 Ubuntu R1 验证，待同批真机复核。

后续已纳入[手机端共享品种搜索与品种信息](mobile-shared-symbol-search-20261114.md)。下文保留最初的局部需求记录；实施范围与验收以合并方案为准。

## 目标

将数据页右上角的搜索入口收敛为只显示搜索图标，去掉当前按钮的边框、背景和圆角底纹，减轻标题栏右侧的视觉重量。

## 实施范围

- 仅调整数据页右上角的搜索入口按钮视觉样式。
- 保留现有搜索行为、搜索列表、搜索接口和数据流程。
- 保留可访问名称、键盘可达性和至少 44px 的触摸命中区域。
- 按现有主题变量适配浅色和深色主题；点击反馈使用轻量的图标/透明态反馈，不恢复实体底框。

## 验收

- 375px 与 412px 手机宽度下，标题栏只呈现搜索图标，不出现边框、背景色或圆角底纹。
- 搜索入口仍可通过触摸、键盘和辅助技术触发，触摸区域不因图标视觉收窄而变小。
- 浅色、深色主题下图标与标题栏对比度合适，点击反馈不造成持续底纹。
- 数据页其他控件及搜索结果行为保持不变。
