## 新增待实现：代码、中文名、供应商组合搜索（2026-11-14）

用户本轮要求记录；下述为已确认需求的具体匹配约定，尚未改代码或部署。

- 覆盖自选页、数据页右上角搜索的全部结果：自选原生、自选自建、数据页原生创建目录。三条读取路径采用同一匹配规则，保持各自可用目录与业务动作。

- 按一个或多个空白拆词（含前后空格、全角空格），**词与词之间为 AND；每个词可以命中任一字段，字段之间为 OR**。不要求用户选择搜索字段或固定输入次序。
- `xau oa`、`oa xau`、`XAU   OA` 均命中 OANDA 的 XAU 品种，排除仅有 XAU 而来源不匹配的结果；`黄金 oa` 同样命中；`xag oa` 命中 OANDA 白银；`oa` 单独搜索可列出匹配供应商品种；`外汇 oa`、`股票 yahoo` 按类别及供应商组合匹配。
- `oa` 按 OANDA 名称子串匹配；供应商搜索覆盖项目真实显示别名，如 Dukascopy / Dukas。自建匹配其列表可见的历史供应商来源，不暗中以实时映射来源替换搜索语义。
- 代码沿用 EURUSD / EUR_USD / EUR/USD 的现有规范化；中文匹配复用简明名称/可靠别名，例如“欧元美元”“黄金”“白银”，处理名称中的分隔符，不依赖整串原始描述恰好包含输入。缺少可靠中文名称时不编造映射。
- 空查询维持当前列表；各关键词允许只输入完整名称的一部分，不增加拼音、拼写纠错、向量检索或单独高级筛选 UI。
- 在服务端匹配**之后**再分页/计数；不能仅过滤客户端已加载的25行，也不能先拉全目录。连续分页不漏匹配结果、不按显示代码合并真实身份。保留当前追加顺序，不在此任务引入全目录排名。

4. 三行信息统一为：代码、简明中文说明、供应商来源。自建在第三行保留与当前自选一致的轻量“自建”标识；原生不额外标“原生”。不把交易状态、周期列表或维护配置挤进这三行。

## 当前交互约定（含真机反馈修订）

### 搜索与筛选

- 沿用现有 shadcn/Base UI 抽屉与主题、返回键、焦点及退场生命周期。面板使用稳定的大容量高度；标题为“添加自选”或“添加自建”，右侧关闭。
- 标题下直接展示搜索框（约 48px 高，带清空入口），默认不自动弹键盘。
- 按真机反馈，自选搜索合并原生与自建到同一结果列表，移除类型标签页；数据页仍仅搜索原生目录并进入创建。
- 自选与添加自建正常搜索均不提供来源/类别筛选，关键词支持这些字段；目录工具迁入次级管理入口，保留空目录恢复路径。
- 自选添加到当前实际分组。处于“全部自选”时沿用既有规则：首个分组；没有分组时创建“自选列表”。移除列表及详情里的“添加到”选组控件，添加成功轻提示实际组名；切换手机当前组后按新组判断重复和添加，不修改桌面 active。
- 最新决定按所有分组全局排除已关注真实品种并提交防重；跨组整理通过管理中的移动，不通过搜索重复添加。现有多组成员不自动清理。

### 结果与后续动作

- 自选结果右侧只放加号；加入中防重复提交，成功后从结果移除，保留查询/滚动并补足结果，允许连续添加其他品种。点击行主体可查看详情，列表不再并列“详情 / 开图”按钮；详情内保留开图。
- 数据页结果右侧使用箭头；选择后进入现有创建设置，不因点击结果直接创建。已存在自建的定位/复用语义沿用现有流程，不再增加选项弹窗。
- 从详情或创建表单返回时保留关键词、筛选、已加载结果和滚动位置。未保存表单仍沿用原有放弃确认。
- 两个入口的查询与滚动状态独立，避免互相污染；不要新增搜索历史、推荐排序或使用计数功能。
- 自建尚未就绪时如实解释原因；沿用 `actionableRow` / `loadManaged` 解析真实行情身份，不用展示代码拼接 ticker，也不增加列表逐项接续请求。

### 自动加载

- 观察抽屉内部实际滚动容器的底部哨兵，提前约 2～3 行触发；键盘缩小视口后仍以该容器为准。
- 查询约 250ms 防抖；查询、类型、来源或类别改变时取消旧请求并重置页链。旧查询结果不能作为新条件的可点击结果。
- 每个当前查询仅一个后续页请求；加载下一批时不清空已显示列表，不跳动滚动位置。
- 合并搜索分别保留原生 cursor/offset 与自建 page，某侧结束后只请求另一侧；每批合并排序后追加，不重排已展示行，不宣称全目录全局排序。任一侧失败保留已有列表并显式重试该批，不悄悄漏掉一类结果。沿用各接口现有结束条件；不为了 UI 统一修改服务端接口。基于真实身份去重，同代码不同来源及不同自建配置不能合并。
- 首次加载仅在结果区反馈；后续加载仅在底部轻量提示。失败保留结果并在底部提供“重试”，不自动反复重试。
- 结果末尾显示低对比“已显示全部”；断网或关闭面板停止后续加载。空结果提供修改关键词/筛选建议。
- 150% 字号与键盘操作下自动加载仍可达，不要求用户只能通过触摸触发。
