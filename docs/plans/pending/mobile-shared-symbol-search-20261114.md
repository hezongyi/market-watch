5. 搜索面板、筛选、结果行、入口按钮共用；加入自选与创建自建保留各自业务流程。

## 补全的交互建议

### 搜索与筛选

- 沿用现有 shadcn/Base UI 抽屉与主题、返回键、焦点及退场生命周期。面板使用稳定的大容量高度；标题为“添加自选”或“添加自建”，右侧关闭。
- 标题下直接展示搜索框（约 48px 高，带清空入口），默认不自动弹键盘。
- 自选保留现有“原生 / 自建”两项切换，默认原生；数据页仅搜索原生目录，不提供多余类型选择。
- 来源默认全部，仅提供一个紧凑的来源筛选入口，不平铺全部供应商。品种类别、目录更新及 Yahoo 补录保留于按需展开的筛选/目录工具中。
- 自选添加到当前实际分组。处于“全部自选”时沿用既有规则：首个分组；没有分组时创建“自选列表”。以轻量“添加到：实际组名”呈现，允许主动更换，不增加必须选组步骤。
- 重复状态按实际目标分组判断，不能用“全部自选”中的存在与否替代目标组成员状态。其他组已关注不阻止加入当前组。

### 结果与后续动作

- 自选结果右侧只放加号；加入中防重复提交，成功变为勾选并留在列表，允许连续添加。点击行主体可查看详情，列表不再并列“详情 / 开图”按钮；详情内保留开图。
- 数据页结果右侧使用箭头；选择后进入现有创建设置，不因点击结果直接创建。已存在自建的定位/复用语义沿用现有流程，不再增加选项弹窗。
- 从详情或创建表单返回时保留关键词、筛选、已加载结果和滚动位置。未保存表单仍沿用原有放弃确认。
- 两个入口的筛选与滚动状态独立，避免互相污染；不要新增搜索历史、推荐排序或使用计数功能。
- 自建尚未就绪时如实解释原因；沿用 `actionableRow` / `loadManaged` 解析真实行情身份，不用展示代码拼接 ticker，也不增加列表逐项接续请求。

### 自动加载

- 观察抽屉内部实际滚动容器的底部哨兵，提前约 2～3 行触发；键盘缩小视口后仍以该容器为准。
- 查询约 250ms 防抖；查询、类型、来源或类别改变时取消旧请求并重置页链。旧查询结果不能作为新条件的可点击结果。
- 每个当前查询仅一个后续页请求；加载下一批时不清空已显示列表，不跳动滚动位置。
- 沿用各接口现有 cursor/offset/page 与结束条件；不为了 UI 统一修改服务端接口。基于真实身份去重，同代码不同来源及不同自建配置不能合并。
- 首次加载仅在结果区反馈；后续加载仅在底部轻量提示。失败保留结果并在底部提供“重试”，不自动反复重试。
- 结果末尾显示低对比“已显示全部”；断网或关闭面板停止后续加载。空结果提供修改关键词/筛选建议。
- 150% 字号与键盘操作下自动加载仍可达，不要求用户只能通过触摸触发。

## 共用品种信息的实现边界

- 从现有 `watchIdentity.ts`、`compactIdentity` 与数据行字段提炼信息映射，拟新增手机共享品种信息组件及纯格式化辅助函数；命名由实施时按项目结构确定。
- 代码、简明中文名、供应商命名、自建标识、字号层级、行间距和缺省规则共用。优先真实品种名称，复用简明名称规则；无可靠中文名不编造，不重复显示代码充当中文说明。
- 保留自选已验收的左侧固定宽度、长代码缩字及 sparkline/价格栏几何；共享组件允许容器宽度适配，不能为搜索列表强制三页同宽。
- 数据页第三行现有维护模式、时区、复权信息移入详情；右侧必要的维护/实时状态与数据时间保留。若同代码、同来源仍存在多个配置，用三行之外的必要短标识区分，详情呈现完整配置，避免误选。
- 提炼共享搜索面板及结果行，注入入口意图与查询适配。保持三个现有读取路径：自选原生 `/market-data/series/page`、自选自建 `/market-data/center/dataset-summaries`、创建自建 `/market-data/history-catalog/search`。
- 原生可关注目录与可维护历史目录的能力范围不同，不默认合并成同一后端结果集合。
