# 手机端头寸计算工具：Dukascopy MT4 美元账户实施方案

日期：2026-11-17。状态：已于 2026-11-17 接入[手机端待实现清单](pending/README.md)，已实施，本地验证通过，开发实例验收中；见[实施记录](../verification/mobile-pending-20261117/README.md)。

## 1. 已确认目标

在 App「更多 → 交易工具 → 头寸计算」提供独立手算工具。账户固定 USD，实际券商为 Dukascopy，首期适配 MT4 外汇及 XAU/USD 黄金。

主流程保持为：**选择品种，输入允许亏损美元金额、入场价位、止损价位，得到风险预算内手数。** 保留多空方向选择；不增加按 pip 输入的第二套模式。外汇自动显示止损距离，例如「20 pip」，方便使用者按 20/40 pip 的习惯核对。

- 允许亏损金额持续记住上次有效值；常用品种、合约参数保存在本机。
- 离线可选品种、手填价格、手填必要换算价并计算，不依赖行情服务成功返回。
- 在线参考价只是可选辅助，可自动初填空的入场价，不能覆盖用户已编辑的输入。
- 只计算价格变化产生的止损风险。佣金、库存费、手续费、额外点差或滑点预算均不进入表单、参数模型或公式。
- 首版不增加净值、风险比例、杠杆、保证金、多账户、止盈、图表联动或真实下单。

结果是按输入计算的价格风险数量，不承诺实际最大损失，也不代表保证金或已有持仓额度已核验。产品内简短使用「按输入价格估算」，不增加复杂说明流程。

## 3. 合约、品种与价格精度

依据 [Dukascopy 官方 MT4 规格](https://www.dukascopy.com/swiss/english/forex/mt4-accounts/#trading-specifications)，2026-11-17 核实的 [规格摘录](../research/dukascopy-mt4-specifications-20261117.json) 包含 59 个 MT4 外汇货币对及 XAU/USD。

| 品种 | 每手大小 | 本工具价格小数位 | 1 pip | 最小手数 / 步长 |
| --- | --- | --- | --- | --- |
| 普通外汇，如 EUR/USD | 100,000 基础货币单位 | 4 | 0.0001 | 0.01 / 0.01 |
| 报价货币为 JPY 的外汇，如 USD/JPY、EUR/JPY | 100,000 基础货币单位 | 2 | 0.01 | 0.01 / 0.01 |
| XAU/USD | 100 金衡盎司 | 2 | 不使用 pip 标签，直接显示美元/盎司价差 | 0.01 / 0.01 |

价格位数按报价货币判断，不能只看名称中是否含 JPY。本工具的 4/2 位是用户指定的简化计算口径，并非修改 MT4 报价精度；不影响 App 其他行情页、图表和上游原始数据。

### 3.1 输入与计算采用同一精度

- EUR/USD 入场 `1.1000`、止损 `1.0980`：实际计算价差为 `0.0020`，显示 `20 pip`。
- USD/JPY 入场 `150.00`、止损 `149.80`：实际计算价差为 `0.20`，显示 `20 pip`。
- XAU/USD 入场 `2600.00`、止损 `2590.00`：显示价差 `10.00 USD/盎司`。
- 手填或参考价超过指定小数位时，在完成编辑/采用参考价时，按十进制四舍五入（half-up）规范化，再参与计算。例如 `1.10005 → 1.1001`、`150.005 → 150.01`。
- 界面显示和参与计算的价格一致，不隐藏第五位或第三位参与计算。规范化后两价相等时，不产生结果；不得沿用原始尾数算出隐藏距离。
- 不在用户输入过程中强行补零、改写内容或移动光标。输入中的空串、未完成小数及待规范化超精度值不输出最终结果；完成编辑后显示规范化值。
- 换算报价使用对应货币对的相同价格位数规则；但倒数汇率、每手亏损、点值的中间计算不能因此只保留 4 位或 2 位。

### 3.2 品种选择完全本地

将核实过的 60 个规格内置在前端，名称、币种、每手大小、最小手数、步长随应用资源可用。搜索和选择都在本机完成，不依赖 `/market-data/series/page`、目录分页、外部元数据或事先在线缓存。

保留原 MT4 合约预设和本机覆盖能力，详情默认折叠；覆盖后显示「自定义」，可恢复内置值。首版仅接受当前模型支持的合法值，不开放任意新产品或计价模型。

Dukascopy 来源 ID 映射作为可选行情参数预置。现有 `stable_id()` 使用规范品种名的 SHA-256 前 32 位并加 `DUKA:` 前缀，可在实现阶段核对后静态生成映射；不在运行时依赖目录查询。某标的行情不可取只影响参考价，不影响选择和手算，也不换到别的供应商。

官方 Max Net Exposure 是净敞口上限，不当成单笔最大数量或剩余可下手数；本工具只输出「风险预算内手数」。

## 4. 计算与 JPY 换算

### 4.1 统一公式

```text
R = 允许亏损金额，USD
D = abs(入场价 E - 止损价 S)
C = 每手基础资产数量（外汇 100000；黄金 100）
X = 1 单位报价/盈亏货币折合多少 USD
L = D × C × X                 # 每手价格止损亏损，USD
Q = 不超过 R / L 的最大合法手数
预计止损亏损 = Q × L
剩余风险预算 = R - Q × L
```

内置规格最小与步长均为 0.01 手：

```text
m = floor(R × 100 / L)         # 整数个 0.01 手
Q = m / 100
```

`m < 1` 时显示「当前风险预算不足最小交易数量」，不向上凑、不显示 0.00 手为可交易结果。若覆盖了合约最小数量或步长，则按该合法集合向下取整，并用相同核心精确回算。

外汇点值用于核对：`每手每 pip 价值 = pip 大小 × C × X`。显示值可四舍五入，但不能拿显示后的点值倒算手数。黄金显示「每手每变动 1 美元：100 USD」，避免把黄金的点、pip、美元混为一个单位。

### 4.2 美元账户的三类换算

| 类别 | 例子 | X 的取值 | 离线所需输入 |
| --- | --- | --- | --- |
| 报价货币为 USD | EUR/USD、GBP/USD、XAU/USD | 1 | 风险金额、入场、止损 |
| 基础货币为 USD | USD/JPY、USD/CHF | 1 / S，使用本次止损价 | 风险金额、入场、止损 |
| 非 USD 交叉盘 | EUR/JPY、GBP/JPY、EUR/GBP | 用报价货币对 USD 的直接或反向换算价 | 上述输入加一项换算报价，或使用上次保存值 |

USD/JPY 的每手每 pip 先产生 1,000 JPY 的盈亏，美元价值与换算价有关，不固定为 10 USD。对 USD/JPY 等以美元为基础货币的品种，用本次止损价 `S` 换算，可避免用入场价导致边界手数超预算；无需额外联网，也不允许另一个手填汇率覆盖这条规则。

交叉盘采用一个固定参考换算价，无法从 EUR/JPY 自身价格独立推导未来的美元亏损。例如 EUR/JPY 使用 USD/JPY，EUR/GBP 使用 GBP/USD；这是按参考汇率的估算，不声称未来汇率不变。

为了降低输入负担，用户填写常见报价 `USD/JPY = 150.00` 或 `GBP/USD = 1.2500`，不要求输入 `1 JPY = 0.006666… USD`。应用按固定映射选直接或反向，核心保留精确比值。按换算货币对记住上次有效值和来源时间，离线显示「上次换算价」；可直接手动替换。没有有效换算价时仅该品种结果待补充，不影响其他品种。

### 4.3 原生整数与精确比值

不增加计算库，使用原生 BigInt 处理固定精度整数和少量分数乘除：

1. 从十进制字符串解析价格：普通外汇乘 10,000，JPY 报价及黄金乘 100；风险金额按美分整数解析，最多 2 位小数。
2. 价格规范化、相减、止损 pip 数都用整数完成。例如 `11000 - 10980 = 20 pip`。
3. 换算率表示为整数分子/分母，例如 USD/JPY `150.00` 对应 USD/JPY 报价 `15000/100`，反向换算 `100/15000`，不先生成浮点倒数。
4. 得到每手亏损的精确比值 `L = a/b`，风险金额为 `r` 美分时，内置 0.01 手规格可直接算 `m = floor(r × b / a)`。所有量均为正整数，不用 epsilon 修补临界值。
5. 用最终手数精确回算亏损，再格式化成两位小数显示。比较预算、手数取整和结果复制前的有效性判断不使用格式化字符串或先舍入的金额。
6. 原生 BigInt 不直接写入 JSON/IndexedDB 参数；持久化原始/规范化十进制字符串，恢复时解析。纯核心不需要保存自己的中间对象。

只需少量解析、乘除、向下取整、格式化函数，不建设通用数学框架。禁止用 `Number.toFixed()` 处理输入规范化，禁止先把每 pip 点值或每手亏损四舍五入再计算数量。

## 5. 在线参考价与离线行为

- 表单和本地品种列表先就绪，行情请求不阻塞输入和计算；不因 `online=false` 禁用工具。
- 联网打开或切品种时可进行一次可取消的参考快照读取；仅在入场价为空、未被编辑且当前仍是同一品种时自动填入，按本工具价格精度规范化。
- 标记「Dukascopy · Bid · M1 参考价」及数据时间。`read_at` 是读取时间，不能冒充报价时间；缓存、失败或闭市旧价不自动覆盖输入。
- 保留「刷新参考价」「使用参考价」：刷新只更新参考区；显式使用才替换已有入场价。需要交叉盘换算时可随本次请求一并读取相应换算货币对；不增加持续订阅、轮询或后台任务。
- 参考价归参考价，价格字段指计划成交价；不伪造 Ask，不把 Bid 参考值标成必然可成交价格。
- 关闭、后台或切品种时取消本工具请求，丢弃迟到响应；网络失败在参考区简短提示，手填结果继续工作。
- 离线不要求先命中在线目录、拥有报价缓存或成功查询账号。工具沿用 App 既有离线进入能力，前端资源可用后不额外验证服务器会话；纯计算核心本身不依赖 profile 或 online。

## 6. 界面与记忆

表单沿用原有价位输入方式：

1. 品种、本机选择器；多空方向。
2. 允许亏损金额，单位 USD，恢复上次有效值。
3. 入场价、止损价，使用品种固定小数位；参考价辅助显示。
4. 外汇显示「止损距离 20 pip」；黄金显示美元/盎司价差。
5. 如为交叉盘，仅在需要时显示一项常见换算报价。
6. 结果突出手数，下方依次显示每手每 pip 价值、预计止损亏损、剩余预算；合约规格详情折叠。

示例：EUR/USD，允许亏损 100 USD，入场 1.1000，止损 1.0980。结果「0.50 手」，辅助信息「止损 20 pip · 每手每 pip 10.00 USD」「预计止损亏损 100.00 USD」。不增加 pip 输入框或输入模式切换。

- 只保存上次有效允许亏损金额、选中品种、合约覆盖及有效换算报价；固定配置为 `dukascopy-mt4-usd-v1`。金额不因切品种或重启丢失。
- 入场/止损保留当前打开期间的草稿；新一轮打开不当作最新行情恢复，避免旧价形成新计划。后台暂离不清草稿。
- 存储适配复用现有本机快照和隔离规则；最后一次编辑顺序保存，空串或未完成小数不覆盖历史有效值。存储失败只影响记忆，当前仍可手算。
- 数值有可见标签和单位、十进制软键盘。失效输入、规范化后两价相等、方向不符或缺换算价时清除旧结果，保留当前输入并就地说明。
- 默认不弹软键盘，自动保存无顶部成功通知；复制仅对当前有效结果可用，内容包括规范化后的价格、pip 距离、换算口径、手数和预计亏损。

## 7. 独立验收算例

以下价格均为固定算例，不是实时价格；全部仅计算价格风险，预算为 100 USD，合约为内置 MT4 规格。

| 品种与方向 | 入场 / 止损 | 换算依据 | 预期手数 | 预计亏损 USD |
| --- | --- | --- | --- | --- |
| EUR/USD 多 | 1.1000 / 1.0980 | 直接 USD，20 pip | 0.50 | 100.00 |
| EUR/USD 多 | 1.1000 / 1.0960 | 直接 USD，40 pip | 0.25 | 100.00 |
| USD/JPY 多 | 150.00 / 149.80 | 止损价换算，20 pip | 0.74 | 98.80 |
| USD/JPY 空 | 150.00 / 150.20 | 止损价换算，20 pip | 0.75 | 99.87 |
| USD/JPY 多 | 150.00 / 149.50 | 止损价换算，50 pip | 0.29 | 96.99 |
| EUR/JPY 多 | 160.00 / 159.80 | USD/JPY = 150.00，20 pip | 0.75 | 100.00 |
| EUR/GBP 多 | 0.8600 / 0.8580 | GBP/USD = 1.2500，20 pip | 0.40 | 100.00 |
| XAU/USD 多 | 2600.00 / 2590.00 | 价差 10.00 USD/盎司 | 0.10 | 100.00 |

必须专门覆盖：

- EUR/JPY 上例每手每 pip 为 `1000/150 USD`，可显示 6.67 USD，但手数必须为 0.75。若先用 6.67 计算会错误降至 0.74；测试要捕获这种提前舍入。
- USD/JPY 多单 20 pip 样例，0.75 手按止损价回算约亏 100.13 USD，必须向下为 0.74。
- EUR/USD 100 USD、50 pip 应精确得到 0.20 手，不因浮点误差降成 0.19；对每个合法边界前后各一美分验证取整。
- EUR/USD `1.10005` 按 half-up 为 `1.1001`；JPY `150.005` 为 `150.01`；两价规范化后相等则无结果。
- 黄金预算仅 5 USD、价差 10 USD/盎司时不足最小 0.01 手，不强行输出最小数量。
- 无报价缓存、网络全部失败时，本地 60 品种可搜索，输入 EUR/USD、USD/JPY、黄金样例均可得正确结果；EUR/JPY 手填 USD/JPY 后也可得结果。
- 刷新失败、存储失败、后台返回、迟到响应均不改变已输入价格或错误阻断手算；参数重启恢复和用户隔离单独验证。
- 375/412px、深浅主题、150% 字号、键盘聚焦和缩小视口、关闭/退场/Android 返回、复制。浏览器和 Android 真机结果分别记录。
