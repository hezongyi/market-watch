# 登录页 Particles 方案与预览边界

状态：最终组件预览完成，等待用户确认；尚未接入正式登录路由。

基线：`main` / `2fe919a`（v1.26.1）。任务分支：`feat/login-particles-preview-20261019`。

## 确认稿

- 保留现有居中卡片、守望标识、字体、深浅主题、密码输入与显示密码、品牌蓝登录按钮。
- 使用 Magic UI Particles 的 Canvas 代码适配，固定上游提交与 MIT 版权声明见 `web/src/app/MAGIC_UI_LICENSE.md`。不增加 UI 框架、连线、拖尾、光晕或宣传内容。
- 灰白粒子随机分布、缓慢自主漂移、轻微明暗变化；卡片周围 120px 内逐步降低亮度。浅色主题使用低对比深灰粒子。
- 最多 96 个粒子，按面积降低密度；绘制调度约 24fps 上限；DPR 上限 1.5，并限制 Canvas backing store 为 300 万像素。鼠标位移影响每轴不超过 2px，不读取点击，也不影响焦点。
- 输入、密码显示切换及提交期间继续缓慢运动。右上角暂停按钮沿用 `mw.login-motion` 偏好并容忍存储不可用；暂停保留当前画面。后台标签页取消绘制调度，前台恢复；减少动态效果时显示静态粒子，禁止按钮覆盖系统偏好。

## 直接复用与确认步骤

`Particles.tsx` 为最终背景组件，`ParticlesLogin.tsx` 为待接入的最终登录页组件。它保留现有登录回调、密码处理、错误后聚焦与密码选择范围恢复逻辑。预览入口直接引用该组件及现有 `app.css`，没有另一套表单或仿制 Canvas。

本轮使用独立 Vite 入口及 Docker 镜像。预览的登录回调只说明当前是外观预览，不调用认证、不伪造登录成功。正式 `Login.tsx`、`main.tsx`、`api.ts`、认证接口和跳转逻辑均未修改。旧取模布点逻辑仍只存在于尚未替换的正式页，预览组件完全不使用该逻辑。

用户确认后，把正式 Login 入口切到 `ParticlesLogin`，删除旧 `DotBackground` 与无引用的 dot CSS；保持 `main.tsx` 中认证请求、CSRF 和 `navigate(next)` 原样。届时在隔离的后端环境补验真实密码、错误密码、会话、直接访问与登录后跳转。不能把本轮预览的提示视为真实认证验收。
