## 1. 冻结范围

冻结页面结构、导航、信息层级、控件与视觉令牌、交互结果和状态反馈。模拟报价、品种、时间、数量不是固定内容。原型的审阅/状态注入/重置/模拟恢复工具不进入产品；模拟 SVG 图表、12 项指标 fixture 和覆盖式十字线不进入真实图表实现。

专业图表内部刻度、原生指标参数/副图界面和手势依据实际组件适配；完整能力须真机验证。若组件无法支持某个冻结入口，先给真实适配证据，不静默删按钮或以模拟能力代替。

## 2. 导航与通用操作

底部五项固定：**自选 → 图表 → 告警 → 数据 → 更多**。均有独立选中态；“数据”不再放到更多，不显示返回更多。

- 首页自选；有会话先读取快照并更新，无会话登录。明确会话过期后进入登录，成功回到合法 `/m/` 路由。
- 自选切到图表/数据详情再返回，保留会话内筛选和滚动；当前自选分组只属于手机。
- 切主入口保留一个图表实例；不拦截图表手势来左右滑动切主页面。
- 系统返回：键盘→最上层弹层→详情上级→一级页→退出。未提交表单返回先选“继续编辑/放弃修改”。重新进入不恢复草稿。
- 退出/换服务器明确不停止服务端告警；清理本机缓存、图表设置和旧连接，按真实登录状态显示。
- 日常业务写入经服务器成功才确认。失败和冲突采用应用内浮动通知，保留当前会话输入；关闭通知后，操作处仍有“尚未保存”。字段校验贴近字段。

## 3. 页面规范

### 自选、搜索与分组

- 左上“自选⌄”整合分组入口；SSE 状态在整条标题栏居中双行显示。右侧依次为添加、管理图标，点击区至少 48 CSS px。
- 正常显示“SSE 已连接 / 最近通信 HH:mm:ss”，通信只来自真实行情事件/心跳；连接中、重连、后台暂停和无订阅状态据实表达。大字号时状态块可到下一行居中，避免遮挡标题和按钮。
- 标题后直接展示列表；没有行情表头、三品种摘要横栏、独立分组栏、底部数量统计/提示及列表尾部告警卡。
- 每行左侧代码/中文名和必要来源、系列标识；中部为宽幅浅面积 sparkline；右侧价格/有符号涨跌幅。行情时间从真实数据取得，来源/系列不能因同名而省略。
- 分组增删改、上下排序、移除/撤销；删除分组不删除全部自选。分组内移除只改成员，全部自选移除同步移出相关分组，文案对应范围。
- 搜索支持代码/中文、现有六源过滤与分页，结果保留真实身份和实际支持周期；已添加状态避免重复，过期请求不覆盖新输入。
- 自选内容与桌面共享，手机切分组不改变桌面 active；409 显示冲突，不强制覆盖。

### Sparkline

- 外汇/黄金 NY17（America/New_York 当地 17:00 至次日 17:00），其他及未知类别 UTC0；分类来自明确元数据。
- 横轴固定完整窗口，未来留白、缺口断线、不压缩休市、不维护各国交易日历。无本窗口数据不替换为前一日曲线。
- 外汇/黄金仅显示伦敦当地 08:00 和纽约当地 08:00 两条无文字参考线，各用本地时区处理 DST；不显示底部短竖线。
- 保留最新有效端点和浅填充，填满品种与价格之间空间；不能按当日已有数据跨度铺满横轴。数据点少或缺日内缓存时保留空白，不伪造走势。
- NY17/UTC0 仅为小图显示规则，不改变供应商开收盘、日 K、涨跌幅和告警口径。小图读取成本和缓存接口见实施任务书。

### 图表

- 顶部一行：左侧当前周期下拉；右侧十字线、指标、告警三个图标。底部仍为五项导航，绘图区占满剩余空间。
- 不放外部品种大标题、报价/涨跌/高低价摘要、保存/加载按钮、手机独立布局说明或行情来源按钮；品种从自选/数据切换。
- 绘图区内部保留一处精简代码和来源/系列标识；原组件已有时不重复。创建告警弹层明确当前真实系列。
- 周期只显示九周期中的实际支持项；改变品种不支持当前周期时按现有能力选有效默认值并给简短说明，不自动换源。
- 指标图标使用 A06 折线/阶梯柱语义；加载运行时完整实际注册目录及项目指标，支持搜索、添加、移除、原生参数和副图。不包含外部社区/Pine 市场，不受 preview 12 项限制。
- 十字线采用原生图表能力，有清楚选中态和辅助名称；支持组件真实触屏定位/退出。离开图表退出查看模式，位置不持久化。A 阶段确认触控接口，不把多图同步当作开关。
- 手机本地仅一份原生序列化图表设置，已应用的系列、周期、指标参数及必要显示偏好自动记住，重进恢复最后成功版本。取消或无效输入不入布局；不创建服务器手机工作区、不修改桌面布局，也不提供草稿恢复入口。

### 告警与事件

- 概况、筛选、规则卡、详情、创建/编辑及记录按 A06；保留真实品种/来源/系列、条件、触价/收盘、周期、次数、到期、通知及最近执行信息。
- v2.0.5 新建/编辑仅支持有能力的组合行情；旧 provider/managed 规则只查看、暂停、归档。固定历史只看图。页面解释不可用原因，不将同名系列自动替换。
- 规则状态使用后端 execution，涵盖准备、监控、休市、恢复、需处理、到期结算、暂停、归档及完成；主标签依据服务端，不能把 active 显示为确定正在监控。缓存规则显示“上次”，数据过时或 worker 状态不明标待确认。
- 表单方向、价格、触价/收盘、实际周期、1/2/3 次、到期、ntfy、名称/备注/迟到处理复用现有后端语义与校验；创建时已在目标一侧不冒充穿越事件。到期含明确时区。
- 保存成功先依返回显示准备/接管状态；暂停/恢复/归档成功才更新。无效能力禁用提交且说明原因，连点不重复创建，超时结果先核查。
- 事件区分触发与异常/恢复；显示服务端实际缺口和不能判定结果。ntfy 服务接收、手机送达和用户确认是不同事实。
- 应用内顶部浮窗提醒新增事件或进入时未处理项汇总；同事件去重，不随重连反复弹。可关闭，关闭不代表已处理；告警角标及记录入口继续可见。不申请系统悬浮窗权限。

### 数据

- 一级页面，平台/自建/组合切换、关键词、来源筛选、详情、支持周期、开图/加入自选、维护和来源状态查看完整可达。
- 区分目录可查询、已有数据、维护暂停/异常和行情陈旧。目录数量不能当历史下载数量。
- 自建显示范围/维护信息，组合显示真实组成和修订；固定历史版本开图保留版本 ID，不按名称重建系列。
- 创建/编辑自建、组合重构、批量补齐和供应商凭据仍在桌面，手机只查看和日常使用；不保留需要再次确认是否扩大的开放项。

### 更多、登录与连接

- 更多保留连接、后台通知/记录、主题、关于、退出；无“数据”重复入口及手机布局管理。
- 关于显示真实 App/服务器/WebView 版本；后台通知说明沿用 ntfy，退出 App 不停止服务器检测。
- 首次配置可信 HTTPS 地址，密码显隐、允许粘贴/密码管理器；区分网络、证书、密码、限流及服务未配置错误，不统称密码错误。
- 不保存密码到业务缓存/日志；超长地址和错误换行。服务器地址切换有明确确认并清理旧本地状态。图表资源失败不阻断自选、登录和数据页面。

## 4. 状态反馈

| 状态 | 展示与行为 |
| --- | --- |
| 有缓存启动/刷新中 | 保留上次内容，报价/小图先灰色；告警/数据标上次；完成对齐后逐项恢复 |
| 首次无缓存 | 骨架占位；空列表只能在成功读取确为空后显示 |
| 断网/读取失败且有缓存 | 内容保留，受影响报价/小图灰色；SSE 连接中/重连；无整页弹窗或顶部断网卡，自动恢复 |
| 离线且无缓存 | 简短无缓存状态，可返回/配置连接，不制造随机报价或永久 loading |
| 单行行情陈旧 | 仅该行报价/小图灰色，SSE 可以仍正常，不弹重复陈旧通知 |
| 提交中 | 明确处理中并禁用重复提交；用户输入保持 |
| 提交失败/结果未知 | 浮窗说明及重试/核查；保留当前会话输入和未保存标记，不跨重进恢复 |
| 409 冲突 | 浮窗与尚未保存；查看最新/返回编辑保留输入，明确放弃输入后才重读，不自动覆盖 |
| 格式错误 | 字段旁提示并保持输入 |
| 会话过期 | 停止写入与订阅，登录后回合法页面；未提交草稿不恢复 |
| 无能力/权限/ntfy 配置 | 原因和可行动作明确；不显示必然失败的可提交状态 |
| IDB 写入失败 | 当前页面可继续用；浮窗说明本次设置没记住，保留上一份成功版本 |

首次在线成功后支持最小页面壳离线冷启动并显示 IDB 快照；不承诺完整离线 K 线/指标，也不做离线业务提交。缓存连接状态不能当实时状态，服务器确认不能由本地颜色推断。

## 5. 实现验收规则

1. A06 是本轮冻结设计，无待选 sparkline 样式或四/五导航分歧；不再追加功能才能开工。
2. 价格、目录、规则、事件、健康均来自真实后端；原型状态选择器不构成业务实现。
3. OPPO Find X8 上验证真实专业图表、触屏十字线、全部注册指标/原生参数/副图及本地恢复；浏览器截图不是 APK 验收。
4. 覆盖当前状态矩阵、离线冷启动/更新、重复提交、409、快速切换迟到响应、进程回收和登录切换。
5. 375/412 宽、横屏、Find X8 实际尺寸、150% 字体、深浅色、软键盘、安全区、焦点和返回无阻断。
6. 桌面布局、最近工作区及 active 不被手机无声修改；共享自选写入仍正确。
7. 触发、执行异常、ntfy 接收及人工确认分别有证据；手机实收单独验证，未知就显示未知。
8. 正式产品移除全部审阅工具、假数据/覆盖层及原型数据库名。交付 APK/版本/测试记录和已知限制，不以“已打包”代表完成。

## 6. 视觉令牌

以 `design.css` 为权威取值。默认深色，浅色同结构；不在业务组件任意添加新颜色。

| 令牌 | 深色 | 浅色 |
| --- | --- | --- |
| 页面 | `#101317` | `#f8f9fc` |
| 表面 | `#191e25` | `#ffffff` |
| 次表面 | `#202732` | `#eaf0fa` |
| 主要文字 | `#edf1f8` | `#172132` |
| 次要文字 | `#a1adbf` | `#536075` |
| 强调文字 | `#91b5ff` | `#275cc5` |
| 主按钮 | `#3669d8` + 白字 | `#285dcc` + 白字 |
| 上涨/成功 | `#5ad2af` | `#087556` |
| 下跌/错误 | `#ff8d96` | `#b72f48` |
| 警示 | `#edc17d` | `#86530b` |
| 分隔线 | `#2c3440` | `#d9dfeb` |

- 采用现有系统无衬线字体和一致线性图标，不新增外部字体下载；价格使用等宽数字特性。
- 字号目标：页面标题 24、列表代码 15、列表价格 18、正文/动作 14–16、辅助信息 12。窄屏价格可降至 16；K 线内部刻度由库决定。
- 原型 `rem` 以 14px 根字号换算，正式版保留等效尺寸并支持系统文字放大。不能禁止页面缩放。
- 间距以 4/8/12/16/20/24 为基础；页面左右 18–20，卡片内边距 16，卡片圆角 12，表单控件 8–10，底部弹层 23。
- 主要操作区目标至少 48 CSS px；原生系统栏按 dp。辅助小按钮若不足，扩大命中区域，不靠缩小字体填更多信息。
- 正常文字对比度至少 4.5:1；图标/焦点可识别。涨跌、异常、选中和禁用都有文字或形状区分。
- 大字号允许名称换行、卡片增高；先保留 A06 三列与中央走势空间，无法容纳时才将走势放到下一行，不缩小点击区，不允许横向溢出或遮住提交按钮。
- 默认只用短促点击反馈；遵守减少动态效果设置，不以动画代替状态说明。

## 7. 可适配边界

实施者可根据真实设备调整换行、安全区、键盘可见区、字体渲染、无障碍命中区、实际可用周期/指标数及后端错误文案；不得凭个人喜好重排冻结 UI。专业图表内部以真实能力适配，不要求逐像素复制模拟 K 线。

若真实组件无法支撑冻结入口，应提供最小真机验证结果与具体替代方案；改动导航、主按钮、页面层级、配色或手机维护/布局同步范围，需要先说明影响再调整设计。不要把 routine 设备适配逐项交给用户审批。

后续执行顺序、接口补充、验证命令、生产边界及 agent 指令统一见实施任务书。本轮只交付文档，不重新发布静态预览，也不开始应用开发。
