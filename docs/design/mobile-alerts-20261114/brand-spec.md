# 项目视觉基线

来源：当前worktree的web/src/mobile/mobile.css、controls.css、components.json和已部署手机页面。项目身份为守望 / Market Watch，图标体系Lucide，shadcn base-nova + Base UI。

沿用系统中文无衬线字体、蓝色主动作、单色辅助图标、浅背景/深文字、暗色灰黑背景与低饱和蓝色。无需营销照片或第三方品牌logo，品种来源以文本呈现。设计稿不伪造设备状态栏。

浅色：text #172132，muted #536075，accent #275cc5；深色：bg #101317，surface #191e25，text #edf1f8，muted #a1adbf，accent #91b5ff。图标触摸区44px，提交48px以上，标签不小于12px。
