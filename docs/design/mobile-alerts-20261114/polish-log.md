- `node docs/design/mobile-alerts-20261114/verify.cjs`：创建价格规则、启用开关、处理事件、无效价格、丢弃确认保留输入；375/412深浅截图20张，无脚本异常、横向溢出。

- Python版 Playwright 未安装。改用现有 Node Playwright 执行 huashu-design 官方 COLLECT_JS，再用官方 Python judge 检查；design-lint.json 无红灯。系统字体和紧凑元信息分隔符为项目已认可样式，保留。
- 检查先等待进场完成；动画中opacity会让对比度检查误判，不能以中途截图验收。折叠详情的非summary内容显式隐藏，避免检查器拿到不可见表单位置。
- 本轮不做生产构建、后端回归、APK或CI；业务代码没有改动。原型不证明真实网络请求、Android手势/返回键、后台通知或告警执行能力已经完成。
