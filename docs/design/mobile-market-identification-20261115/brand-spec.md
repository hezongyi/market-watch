# 视觉依据

沿用项目已认可的守望 / Market Watch 手机视觉：系统中文无衬线字体、Lucide 同类线性图标、蓝色主操作、中性轻量标签、44px 图标目标和48px主按钮。不伪造 Android/iOS 系统状态栏。

色值来自当前工作树 mobile.css：浅色 text #172132、muted #536075、accent #275cc5；深色 background #101317、surface #191e25、text #edf1f8、muted #a1adbf、accent #91b5ff。

主角素材就是品种信息和真实业务字段，不添加营销图片或供应商品牌 logo。供应商名称是价格来源标签，不是品牌物料。HTML 全部资源内嵌，可离线打开。

版面来自选品流程：先展示确定价格系列的选择，再展示来源产品和创建配置，最后展示日常列表；三行信息及轻量标签承担辨认任务。
