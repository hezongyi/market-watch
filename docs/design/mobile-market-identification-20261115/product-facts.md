# 事实与示意边界

宁德时代六种原生价格系列的代码、市场、来源、复权与周期依据本轮实际 Ubuntu API 响应，见相邻统一标识方案。两处添加分别使用价格系列目录与历史来源产品目录，不能视为相同对象。

原型里的价格、折线、历史日期、实时开关和自建配置为明确标注的示例，不查询或写入真实数据。永续示例使用“示例来源／待核实”，仅展示现货与永续的识别方法，不代表本项目已经提供该产品。

四个界面初始为用于比较语义的展示快照，不是实际用户自选/目录的同步副本。局部交互模拟搜索、添加留行、创建后目录排除、详情、配置与实时开关；不会据此宣称已完成后端集成、防重或 Android 验收。模拟创建不自动添加到自选。未覆盖的图表/告警/更多导航在原型中禁用。

未增加真实供应商能力。股票自建示例只提供当前来源目录可表达的不复权；不会因为原生不复权入口支持分钟线，就承诺该历史维护入口也有分钟产物。D1派生和无分钟来源不画日内曲线。

第四版新增分类 fixtures 是界面覆盖样本，使用“示例来源”避免暗示已接入真实供应商。合约代码/日期仅用于区分展示，不构成可用或有效合约承诺。此类样本可选择查看创建顶部样式，但禁用创建动作；基础表单沿用既有示意。BTCUSDT 交割合约用基础代码加右侧完整短日期辨认，详情保留完整代码。预览市场映射显式定义，不根据代码猜资产类型；实际接入仍须核查供应商元数据。
