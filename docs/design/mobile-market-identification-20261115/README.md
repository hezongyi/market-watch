# 手机端行情标识交互预览

## 第四版：分类覆盖

第四版补齐完整分类：股票市场、外汇、贵金属、股指、指数、期货、加密、ETF、基金、债券、期权、商品和待分类。代码旁仅一个彩色主标签，右侧以普通文字显示现货、永续、交割日期、主力连续、合约月份或 CFD。同族共用低饱和色系，未知类别使用中性标签。


第三版按最新反馈：深A、沪A、外汇等市场使用轻量彩色标签；来源完整显示新浪财经、腾讯财经。创建设置沿用当前 App 表单结构，仅顶部品种信息同步添加自建的两行左右布局；自选主列表保持原样。前两版归档为 preview-v1.html、preview-v2.html，不随线上单文件发布。

设计稿：直接打开 [index.html](index.html)。完整语义与实施边界见 [统一标识方案](../mobile-market-identification-20261115.md)。

四屏为添加自选、添加自建、创建设置、添加后。桌面可同时比较，手机用顶部导航切换。可操作多词搜索、原位添加勾、查看详情、来源选择、模式切换、周期选择、模拟创建与实时开关，并切换深浅主题及放大文字。

静态原型操作只作用于页面内存；品种能力、示例数据及同步边界见 [product-facts.md](product-facts.md)。业务代码和真实自选未修改。
