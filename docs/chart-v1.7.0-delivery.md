## 阻断修复与复审

- 原生线程 reset/purge 复用线程但替换缓存。储备成功、空终点、miss 和失败全部先验证线程、缓存对象、首柱游标与必需加载状态；共享退避与终点按缓存代次重建，旧响应不能结束新缓存或消耗新预算。
- Yahoo 储备使用持久化元信息，不在元信息 TTL 过期时同步请求上游；未解析元信息返回可重试 503，普通必需读取继续按既有 TTL 刷新。缓存命中和 miss 都不调用上游。
