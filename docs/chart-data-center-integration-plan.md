# 图表内数据中心：布局、交互与实施方案

日期：2026-10-08。状态：已实施；原实现验收已归档。入口位置、原生弹窗UI、指标图标及平台目录调整已验收通过，用户验收实例保持运行。
本轮结果与实际启停见[UI验收记录](verification/chart-data-center/native-ui-20261008/README.md)。

基线：`6fd9273`。方案依据本地源码与用户对生产页面的描述，不代表已核验生产当前构建。
本方案取代旧《数据中心组织与UI设计》中独立页面、应用侧栏入口及应用外壳配色的安排；
原有行情三层模型、数据身份、发布版本、维护任务、引用保护与权限规则继续适用。

## 1. 目标与范围

数据中心成为图表工作区内的管理功能。唯一常规入口位于图表上部工具栏“指标”入口之后，点击打开窗口，
视觉与操作习惯对齐现有指标窗口。用户在同一窗口内完成查找、查看详情、新建、维护、配置映射及任务处理。

本轮设计面向桌面浏览器，覆盖1024、1440、1920px视口及200%缩放；不新增移动端专用布局。
实施时复用现有业务能力，不改变行情来源含义、需求生命周期、后台调度或数据删除规则。
本轮实施与验收在Ubuntu隔离实例完成；正式生产发布另需明确授权。

当前检查的公开接口未发现可承载整套管理界面的通用原生弹窗扩展接口。
因此定义为“图表公开工具栏接口 + 自定义管理窗口”，不宣称复用了库内部完整弹窗组件。
不修改许可库bundle，也不依赖其私有React组件。图标按钮使用公开原生样式扩展接口并装饰SVG，样式对齐原生工具栏。实测HTML扩展存在禁用测量副本，原生回调能准确响应可见按钮。
公开API支持左右对齐；按创建顺序依次接入指标、数据中心、行情搜索，须验证指标后的相邻位置、
窄窗口溢出、禁用测量副本和点击绑定，若无法仅靠公开接口保证相邻位置，应记录限制并评审适配方式。

## 3. 唯一入口与兼容

工具栏“指标”入口之后使用数据库形状的线性SVG图标加“数据中心”文字，图标与文字垂直居中；命名与提示均为“数据中心”，声明打开dialog的语义。
尺寸、笔画、悬停、键盘焦点和选中状态与相邻按钮一致。初版不显示后台任务角标。
每个图表工作区仅有一个入口与一个窗口实例，多图布局不重复生成入口。

移除应用侧栏入口、行情搜索中的“去数据中心”链接、回测中的维护跳转及其他外部直达入口。
保留数据未就绪原因，并改为说明“请从图表顶部的数据中心维护”。数据中心内部对象间导航继续保留。

旧`/market-data`列表、详情、版本和配置链接兼容到图表工作区，再打开同一窗口并定位目标。
这是历史地址兼容，不保留独立数据中心页面，也不新增可见菜单入口。
已有工作区优先复用，不能因兼容跳转覆盖已保存布局；无工作区时沿用现有工作区初始化流程。
只接受已知子路径及白名单查询参数，保留对象、分区、版本、周期等定位信息。
失效对象在窗口内显示原因及返回列表操作；未登录按原认证流程恢复目标。

## 4. 窗口布局

默认约1120×720 CSS px，宽高均受视口减32px限制；居中，跟随图表深浅主题。
左侧导航176px（窄窗口136px），右侧为内容区。弹窗左上角使用同款图标加“数据中心”标题；边框、圆角、遮罩、字体、强调色沿用原生图表窗口规范。
正文以14px为基准，标题20px/600，标题栏68px、圆角6px及轻投影对齐当前原生设置/指标弹窗。
深色使用#1f1f1f中性灰、浅色白底；导航采用平直灰色选中行，控件与表格避免应用外壳的绿色或蓝灰卡片样式。
主操作采用原生黑白按钮，链接和键盘焦点保留蓝色。间距按4/8px步进。表格日期与数量使用等宽数字。

```text
┌ 数据中心                                                   × ┐
├────────────┬─────────────────────────────────────────────────┤
│ 自建行情   │ 自建行情                            ＋添加行情   │
│ 平台品种   │ 搜索品种…                 来源 ▾    更多筛选 ▾  │
│ 组合行情   │ 全部  可用  准备中  需处理  已暂停  已归档       │
│ 任务与记录 ├─────────────────────────────────────────────────┤
│            │ 品种与口径 │ 可用历史 │ 周期 │ 维护与状态 │ 操作 │
│            │ …                                               │
│            │                                                 │
│────────────├─────────────────────────────────────────────────┤
│ 来源与能力 │ 更新时间…                         共…条  ‹  ›   │
└────────────┴─────────────────────────────────────────────────┘
```

标题、筛选和分页保持可见；中间内容独立滚动，不产生多层整页滚动。
窄桌面或放大时筛选换行，降低次要列密度，必要横向滚动限于表格，品种、状态、主要操作保持可达。
不设统计卡片首页，不自动根据当前图表过滤全部数据；后续可增加明确可取消的当前品种快捷筛选。
首次打开默认自建行情；后续恢复上次浏览位置，历史深链接定位优先于记忆状态。

## 5. 分区及信息层级

| 分区 | 默认信息 | 操作与约束 |
| --- | --- | --- |
| 自建行情 | 品种、来源/价格口径/日界、可用历史、周期、维护与可用状态 | 添加行情、查看、打开图表；同名不同口径分别展示 |
| 平台品种 | 来源品种、原生周期、M1历史能力 | 搜索、打开平台图表、添加自建、配置原生参数；浏览不自动创建历史 |
| 组合行情 | 品种、历史来源、实时来源、接续状态、周期 | 查看、配置映射、打开组合；浏览候选不建立使用需求 |
| 任务与记录 | 对象/类型、固定范围、阶段与进度、更新时间、错误摘要 | 按现有允许动作暂停、恢复、重试；详细错误按需展开 |
| 来源与能力 | 已接入来源、周期/历史/实时能力、配置说明 | 与实际连接健康分开表述；没有健康API时不推测“连接正常”；不显示凭据 |

每个分区只强调一个主要动作。行内优先保留“查看”及适用的“打开图表”，低频动作收进更多菜单。
状态用文字辅以颜色；可用历史和本次维护异常分别展示。筛选支持全部、可用、准备中、需处理、已暂停、已归档，
维持现有后端语义，不把可用与需处理误当互斥状态。搜索、防抖、分页与服务端过滤沿用现有能力。

## 6. 详情与表单

点击查看后右侧替换为详情，左栏保持。返回恢复对应分区的筛选、页码、行位置及焦点。
不新增第三列详情侧栏，不叠加整套管理弹窗。

```text
← 返回自建行情列表
EURUSD                                      在当前图表打开
Dukascopy · Bid · NY17
概览 ｜ 覆盖与质量 ｜ 发布版本 ｜ 维护设置 ｜ 组合与引用
──────────────────────────────────────────────────────────
页签内容…
```

自建详情沿用上述五个页签；组合详情使用概览、接续与修订、使用与健康。
现有详情中的完整行情图表改为向主图表打开；覆盖与质量中用于解释数据质量的可视化可保留。
“打开此版本”携带明确版本身份，“在当前图表打开”按既有系列解析规则执行，不混淆最新与固定版本。

新建、维护、原生参数、映射配置都在右侧内容区完成。新建的逻辑顺序为来源/品种、口径/日界、
历史范围/维护计划、核对并提交；简单表单可同页分组，不强制拆成多步。
保存成功进入相应详情，字段错误保留输入并就地提示。切换分区、返回或关闭前统一执行未保存修改检查。
提示在当前窗口中呈现继续编辑、放弃修改；保存动作仅在当前表单允许提交时提供。
删除及引用影响确认维持原有安全规则，可在当前内容区完成确认，不把普通关闭和取消等同于删除。
固定版本回测等现有能力继续保留；离开图表前完成未保存检查并携带准确版本与范围。

## 7. 图表联动和窗口生命周期

| 触发 | 预期行为 |
| --- | --- |
| 打开窗口 | 记录工作区身份、活动图格和触发焦点；图表继续运行，不重新挂载 |
| 浏览/搜索/详情 | 读取管理数据，不创建实时需求或维护任务 |
| 在当前图表打开 | 发送明确系列/版本/周期及目标图格，使用既有解析和需求流程；成功后关闭 |
| 打开图表失败 | 保留窗口、选中对象及错误原因，允许重试；不将失败误报成功 |
| 目标图格或工作区已变化 | 校验工作区世代与图格身份，停止过期操作并提示重新选择，不静默改写其他图格 |
| 已提交维护后关闭 | 后台任务继续，重新打开查看真实进度 |
| 普通关闭 | 保留本会话分区、筛选、分页及位置，焦点返回工具栏按钮 |
| 刷新页面 | 可恢复浏览定位；未保存表单不承诺跨刷新恢复，提供离开保护 |

多图情况下只修改目标图格，不能意外同步替换其他图格；须与已有品种同步设置联合验收，
实现前核实可用API及同步协调机制。不能仅假定调用activeChart().setSymbol就满足隔离要求。

右上角×和Esc关闭，点击遮罩不关闭。存在下拉菜单时Esc先关闭菜单，再处理窗口关闭。
窗口内Tab焦点受限，关闭后还原焦点；加载、轮询与后台状态更新不抢焦点。
重复点击入口不生成多个窗口。打开时协调已有指标/原生弹窗，不叠加可交互管理窗口。
加载时保留框架；轮询失败保留上次成功数据并标记快照时间；初次失败与真实空列表明确区分。
关闭时取消窗口读取请求与轮询，已经明确提交的后台任务继续，不把中断响应理解成提交失败。

## 8. 实施结构与顺序

推荐由现有React应用持有数据中心控制器、业务组件与API会话，通过图表桥接接收打开/关闭/应用系列消息。
工具栏按钮位于图表host；窗口优先由应用层渲染，主题、焦点、遮罩与图表全屏容器协调。
若全屏宿主限制应用层可见性，应调整承载点并保持同一控制器；先验证，不直接嵌套完整旧页面。
管理内容内部导航与工作区路由分离，防止列表/详情切换触发图表卸载。
桥接沿用现有可信origin/source/session校验、消息关联与超时处理，不开放任意URL或任意API调用。

1. **接入验证**：确认图标位于指标之后、溢出行为、窗口承载、全屏/最大化、主题、焦点、主图表存活和多图应用语义。
2. **窗口与导航**：实现外壳、五个分区、浏览记忆、内部导航和未保存修改守卫。
3. **业务迁移**：复用列表、详情、表单、任务操作；将图表打开动作转交主工作区，保持版本和日界等身份信息。
4. **入口收敛**：迁移旧地址，删除外部可见入口，覆盖行情搜索、回测和内部交叉引用。
5. **验收**：在Ubuntu隔离实例完成真实数据链路及浏览器检查，形成证据后再安排正式发布。

原业务API优先复用；发现缺失信息时记录明确契约差异，不在UI中推算后端就绪或允许动作。
实施文件预计涉及`advanced-host/bridge.js`及新增host入口模块、`AdvancedWorkspace.tsx`、
新增数据中心控制器/窗口样式、`market-data`组件、`main.tsx`兼容路由和相关浏览器用例。
后续实现须同时更新旧UI方案的状态，避免两套入口规范并存。

## 9. 验收标准

| 范围 | 必须通过 |
| --- | --- |
| 唯一入口 | 工具栏“指标”入口之后一个图标；侧栏/行情搜索/回测无额外直达入口；多次点击只有一个窗口 |
| 原生一致性 | 深浅主题、按钮状态、窗口层级、全屏与最大化正确；原生适配和报价hook按后续专项方案固定版本及SHA256校验 |
| 图表保留 | 打开、分区切换、查看详情、关闭不重挂载图表；指标、画线、布局与视图位置保留 |
| 图表应用 | 平台/自建/固定版本/组合身份正确；仅目标图格变化；同步设置、过期图格、失败重试均覆盖 |
| 管理流程 | 添加→后台准备→发布→打开；维护/暂停/恢复/重试；映射配置；版本、引用、归档及受保护删除均可完成 |
| 数据副作用 | 仅浏览不新增需求；明确打开图表或提交维护才产生对应业务动作；关闭不误停后台任务 |
| 导航兼容 | 旧列表/详情/配置/固定版本链接进入同一窗口；返回恢复位置；失效对象可恢复；无工作区与认证回跳覆盖 |
| 编辑与并发 | 关闭/返回/切分区均保护未保存输入；快速切换、重复提交、超时和轮询不串写或清空输入 |
| 可访问性 | 键盘全流程、焦点限制与返回、Esc层级、图标命名、文字对比度、状态播报正确 |
| 桌面布局 | 1024/1440/1920px、200%缩放、长中文及长品种名可读；表格局部滚动，主要操作可达 |
| 异常反馈 | 初次失败、空列表、筛选无结果、旧快照、维护失败但历史可用均有准确反馈 |

UI fixture只证明布局和交互；真实业务验收使用Ubuntu本机独立Compose project、网络、volume、数据库与端口。
Docker构建必须通过`mw-docker build`或`compose-build`，明确task/project/用途；不得在unraid创建验收实例。
实施交付记录实际主机、访问地址、启动/停止命令、构建版本、测试结果及截图来源。
生产发布需另有明确授权。任务完成后的资源退役遵循`mw-docker retire`清单及备份恢复验证要求。
