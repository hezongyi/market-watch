# 数据中心「来源状态」实施方案

日期：2026-10-10。状态：范围已获用户认可；供后续实施使用。

## 1. 目标与首版范围

左侧新增第五个分类「来源状态」，位于「任务与记录」下方。将目前出现在所有分类顶部的 OANDA 实时状态迁入该页，让行情分类直接展示列表。

首版承接 OANDA Practice 的现有状态快照，页面结构支持后续扩展来源。展示当前状态、数据时间与可展开的诊断详情。连接事件时间线、其他来源状态接入及主动重连／账户校验等控制操作另行规划。

## 2. 页面与信息层级

| 区域 | 内容与行为 |
| --- | --- |
| 页面标题 | 来源状态；显示最近成功读取时间，提供「刷新状态」按钮 |
| 来源概览 | OANDA · Practice，简明说明当前实时供源状态及已记录的异常 |
| 品种列表 | 商品代码、实时报价是否就绪、最后报价时间、完成 K 线是否就绪、最后确认分钟柱、交易时段 |
| 诊断详情 | 连接状态、鉴权暂停、恢复状态、错误说明与原始错误码、心跳及相关时间；默认折叠 |

沿用数据中心现有原生侧栏、列表、详情和明暗主题。时间显示明确时区。窄屏和缩放时字段可换行，诊断详情不挤占行情分类的空间。

「任务与记录」继续承接历史下载、维护任务和执行结果。来源页可说明历史读取情况，但只有取得匹配账户、品种和时间范围的真实请求记录时，才能展示其结果；首版现有实时接口没有该证据时，显示「暂无历史请求状态」，并引导至相关任务或行情详情。

## 3. 状态与时间规则

| 情况 | 展示规则 |
| --- | --- |
| 首次读取未完成 | 「正在读取状态…」；不判定上游正在恢复或连接失败 |
| 状态接口读取失败 | 「状态暂时无法读取」；保留上一份结果及其读取时间 |
| 后台记录 timeout | 「后台记录请求超时」；展示实时就绪结果，不推断所有 REST 接口均不可用 |
| 报价与 K 线确认 | 分别使用 quote_ready 和 candle_ready，分别说明实际影响 |
| 已核实闭市 | 普通「闭市」标签，附已核实的下一时段信息；不算连接故障 |
| 交易日历未核实 | 「时段尚未核实」；不自行推断周末闭市 |
| 来源未配置／无采集记录 | 分别说明；不显示正常或连接失败 |
| 鉴权暂停 | 明确「鉴权暂停」及处理建议；不使用刷新按钮解除暂停 |
| 已过期的检查时间 | 诊断中标注「原计划检查时间（已过期）」；不继续称为未来的「下次检查」 |

页面成功轮询只证明状态接口可读。来源心跳、报价时间、分钟柱时间和错误观察时间各自保持原本含义；不得将页面读取时间冒充后台状态更新时间。缺少错误发生／观察时间时显示「时间未提供」，不得用当前时间补造。

页面只读取后台快照。刷新和自动轮询不新增行情订阅、不启动采集、不触发历史下载或后台重试；切换分类、关闭窗口时取消请求与轮询，迟到响应不得覆盖新页面。

## 4. 实施锚点与接口

以下路径相对 Market Watch 仓库根目录：

- `web/src/market-data/Window.tsx`：新增侧栏项和图标，沿用既有导航、焦点与位置恢复行为。
- `web/src/market-data/location.ts`：新增 `tab=sources` 白名单与分类解析；恢复地址可正确选中该分类。
- `web/src/market-data/Center.tsx`：加入来源页分支，将公共顶部 `LiveProviderStatus` 改为仅在来源页呈现；显式处理分类，保留任务页路由。
- `web/src/market-data/LiveProviderStatus.tsx`：整理为来源概览、品种列表与诊断详情，修正首屏读取及过期时间文案。
- `web/src/market-data/useSnapshot.ts`、`window.css`：按需扩展手动刷新及页面布局；复用现有 10 秒轮询和请求取消机制。
- `backend/alerts/live_api.py`、`live_pricing.py`：复用已认证的 `GET /api/market-data/live/status`。现有快照包含连接、心跳、报价、分钟柱及就绪状态；来源错误观察时间、配置状态等缺失信息仅从对应权威记录补充，使用可空字段并保持原接口兼容。不能用鉴权探测时间代替其他错误的发生时间。

实施不调整采集、鉴权或历史下载的业务规则。页面结构可扩展其他来源，但首版只展示有真实接口证据的 OANDA 状态。

## 5. 验收与交付

在 Ubuntu 独立 worktree 和 Docker Compose project 实施及验收，按仓库规则使用 `mw-docker` 构建和精确退役。

- 原四个分类不再出现全局 OANDA 诊断区；来源页可进入、关闭并恢复导航位置。
- 覆盖首次加载、读取失败且保留旧结果、正常、闭市、时段未知、超时、鉴权暂停、未配置和无采集记录；模拟状态只在隔离验收中使用。
- 过去的检查时间不作为未来安排展示；页面读取成功不让旧来源记录看起来已更新。
- 实时异常不推断历史不可用；缺少历史请求证据时明确显示暂无状态。
- 浏览、刷新、离开页面均不新增采集需求或触发控制命令；轮询取消和过期响应隔离正确。
- 原生与兼容窗口、键盘、明暗主题、375px 窄屏及 200% 缩放下可操作，页面无横向溢出。

交付包含实现差异、Ubuntu 验收地址、启动／停止方式及验证结果。生产发布作为后续独立交付步骤。
