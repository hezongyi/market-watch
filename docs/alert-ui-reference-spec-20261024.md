## 行为与边界

- 单击行选中并定位，双击/设置编辑；高级菜单进入独立详情覆盖层，保留健康、完整身份、触发次数/证据和原停止手机提醒入口。
- 未读交易日志独立统计，只在日志实际可见时viewed；垃圾桶使用viewed/handled，从默认列表收起，保留原始事件和手机提醒。整批清理只捕获当时已加载可整理集合（最多100），有界并发4；失败保留、可找回。
- 可选display_identity和notice字段向后兼容；历史身份只读取冻结证据，上次触发从SignalRow批量聚合。旧草稿默认自定义名称，不自动改名。
- 新事件冻结alert_created_at供摘要；老事件缺该时间时省略创建行，不用触发/更新时间冒充。
- 简单价格对常数使用原生展示primitive负责线/价格轴，v31.1.0局部适配器读取主系列实际priceToCoordinate绘制标签/垃圾桶和圆点。未知ATR阈值、指标单位、错图或旧generation不画。
- 垃圾桶归档携带version/control_revision/request_id；失败保留线。该适配不调用broker、不修改vendor、不写chart document/undo。
- 编辑保持原始十进制字符串；没有最小tick契约时不启用Number步进。新增条件入口明确当前只支持单条件，通知保持网页/ntfy。
