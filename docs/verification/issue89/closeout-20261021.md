## Change and risk

F1: persisted provider-bar comparison, historical epochs and indicator snapshot
consistency. No schema or credential-format migration. OANDA foreground history
and REST writers now share a candle contract. Canonical **complete old and new
payloads** compare equally for completed missing/true flags and exact valid
decimal forms. Equivalent writes retain the exact stored payload, epoch, bar
revision, price freshness and frozen prefix. Observed time and dataset commit
revision still advance. Explicit false, forming semantics and real OHLC, volume,
validity, label, gap and completion changes remain significant. Other providers
retain their comparison rules.

Native acceptance exposed a further failure: empty-cache network errors were
converted to nonterminal empty data, repeatedly recreating native sources.
Ordinary failures now reach the native error callback as its required string,
with structured errors retained internally. History reload and viewport recovery
share a 15-second budget and cancel only the exact owning range operation,
preventing late mutations. Explicit retry after failure reloads the failed source.
Cancellation, capacity and accepted-cache paths retain existing behavior.

Default Uvicorn logging did not emit the new INFO diagnostics. API startup now
enables only the snapshot rejection logger and supplies stderr when it has no
handler. Public error code/message are unchanged. HTTP `X-MW-Attempt-Ref` matches
redacted reason/version records; tokens, accounts and price payloads are excluded.
