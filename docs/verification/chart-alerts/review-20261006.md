## Standards

0 项硬性标准违规。独立 worktree/Compose、Ubuntu、本任务网络和数据库、`/tmp`私密配置、许可资源忽略和未部署声明符合 AGENTS。

2 项启发式发现：保存与判定重复维护 timestamp/index/未来日历映射；runtime dict 的关键字段缺少集中类型合同。前者已提取 `chart_geometry_mapping.bar_indices`，API和worker共同调用；后者仍是维护性建议，当前不涉及运行正确性的已证实缺陷。
