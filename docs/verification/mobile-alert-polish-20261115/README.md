# 手机告警页打磨

日期：2026-11-15。工作区 `feat/managed-live-rollover-20261113`，HEAD `17af8e25`，保留此前已实现但尚未提交的工作。本轮基于既有告警全流程实施做布局、文案和控件打磨，分类 P0；未改变 API、判定、生命周期、通知执行或数据存储格式。

## 交付变化

- 规则主信息使用完整行宽分配品种与条件，启用开关放在状态所在行，并使用已有大尺寸 Switch。主信息点击与开关的触摸区域独立，三行身份和条件不再为顶右开关让出额外列。
- 常规规则行保持约 133px 的紧凑密度，次要说明和执行状态使用可读字号。超长代码在列表略缩字号，详情允许身份与状态分行，避免孤立尾字符挤占条件。
- 自定义范围或查询在列表显示真实筛选条件，提供无框叉号一次清除。空态和读取占位去掉装饰边框，失败就地显示并保留已读规则。
- 规则详情先呈现身份、执行状态和条件；暂停/恢复、编辑及不确定结果核查位于记录、图表和排查入口之前。归档保持末尾与原确认语义。
- 表单去掉重复的“设置触发条件”和静态默认说明，价格占位文字恢复普通字号，值继续突出显示。通知说明、设置入口和大开关组合在同一字段内；实际次数、到期、迟到摘要保留。
- 触发记录以代码为主、简短名称/来源为辅，未处理使用轻量标记，价格标明“触发价”。处理本次提醒与失败信息置于技术详情之前；已处理后不再保留未来时的操作说明。

仅使用现有 shadcn/Base UI 控件及主题、Drawer 动效；没有新增依赖或改动自选报价主体、sparkline、专业图表与网页告警界面。
