# 固定历史图表与引用回收阶段验证

日期：2026-10-06。本阶段延续[第二层报告](managed-center-stage.md)，不表示完整三层收口。

## 行为

- 固定版本图表默认读取最新观测，每页最多 2000 根，通过排他时间游标向前分页。
  查询走周期分块索引，仅解压所需块，不逐次扫描全部 M1。
- 首次打开图表将具体版本固定到 URL；切换周期仍使用该版本，只开放其已发布且有观测的周期。
- 自建详情与固定图表提供回测入口，明确传递固定版本；进入页面不会自动执行演练或建立实时需求。
- 引用页列出固定回测、策略、预警版本/事件、保存工作区、跨数据集派生、活动任务和图表租约。
  暂停并归档后，只有无引用历史可回收；提交时重新核对引用与任务。
- 回收价格分块、周期产物及该数据集的行情查询产物；不可变身份、发布清单、来源关联及回收记录保留。
  回收记录不可由普通运行写入修改/删除。共享 M1 若仍被其他历史或来源采集缓存引用则保留。
- 回收后旧版本不再可读或用于回测/派生。重新维护生成新版本，不恢复旧版本号的价格内容。
- 数据库删除释放的空间供数据库复用，不声称该过程等量减少宿主文件系统占用；未做全局 vacuum/prune。

## 并发与兼容

回收与新引用在同一数据集锁下检查、写入；固定价格读取持有共享锁，避免查询中途删除内容。
旧裸 ticker 在前序迁移尚无历史表时不触发新身份检查。
普通 ORM 持久引用写入使用统一保护；已有工作区乐观 SQL 更新也显式取得相同保护。
历史下载任务与派生任务采用数据集在版本/品种之前的锁顺序；网络请求仍在事务外。
将来增加组合引用时，需在同一保护接口声明其身份字段并覆盖并发场景；其 FK 依赖会阻止未处理回收。

迁移 `ac30_history_reclamation` 保留发布版本记录，新增历史回收和提交幂等记录，使用固定 DDL。
实际 Ubuntu PG 已升至此版本。全链迁移与已有旧表测试保留旧队列、预警及版本含义。
