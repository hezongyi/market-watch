## 实现范围

- 从认可稿直接迁移字体栈、色彩、字号、字重、行高、间距、导航 SVG 和控件外观。视觉覆盖集中于 `web/src/mobile/watch-a07.css`，限定自选页及其打开的弹层。
- 自选主屏、搜索添加、分组选择、管理自选，以及加载、空列表、离线缓存和事件通知状态。修正搜索输入框换行、原生 dialog 两侧缩进、150% 字号页头重排。
- 保留现有 API、SSE、缓存、真实价格和迷你图窗口逻辑。缺失行情不补造；未到的时间留白，不复制原型示意曲线。
- 指定分组支持上下移动并通过现有保存接口持久化；全部自选继续按分组顺序去重汇总，不增加全局排序存储。保留冲突草稿、未保存退出确认与高级分组编辑。
- 自动会话刷新遇到网络失败且自选已有用户缓存时，使用页内离线提示，避免重复错误浮条覆盖标题。主动操作失败及其他页面提示仍保留。

本轮没有将图表、告警、数据、更多四个主页面迁移至 A07；工作区中这些页面的已有修改来自此前 A06 工作。
