# 自选页面左侧品种信息设计决策

日期：2026-11-12
状态：已确认，用户随后授权实现；见 ui-a07-kind-source-20261112.md

用户确认后续按方案 A 调整自选页面左侧信息：

```text
EURUSD
平台 · Yahoo
```

```text
BTCUSDT
平台 · 币安
```

第二行固定展示两项：

- 行情种类：平台 / 自建 / 组合
- 供应商源：Yahoo / 币安 / Dukascopy 等

代码作为主信息，行情种类与供应商源作为次级信息。品种中文名称暂不作为左侧常驻字段，可继续保留在详情、标题或辅助无障碍文本中。后续实现需保持当前右侧价格列、sparkline 高度与行布局不变，并针对 375px 和 412px 宽度验证长代码、长供应商名称的省略表现。

本次仅记录决策，未修改 UI 代码、未构建、未部署、未更新 PR 或 CI。
