## 截图打磨与修复

1. 真实旧版截图显示代码和长说明挤成粗体段落、单卡占高较大，来源筛选/分类/任务入口与其他页面不一致。最终将代码、说明、来源/周期分层，主次操作统一，减少重复标签。
2. 第一轮详情截图确认基础主题与 Drawer 尺寸；修正来源状态字段，分别呈现来源能力、目录同步、实时配置与品种就绪，避免把“配置”称为“已连接”。实时报价和完成 K 线就绪分别展示。
3. 第二轮 375px / 150% 截图发现完整版本 ID 抢占卡片。改为短版本号、中文时间范围、状态；完整 UUID 放入展开区，开图仍使用完整身份。事实标签列改用 rem，修正大字号时的标签/值间距。
4. 目录和详情错误用内联 Alert，避免重复通知覆盖入口；会话刷新在数据页出现网络失败时也依赖已有离线提示。搜索焦点移除内部重复描边。
5. 关闭面板取消请求，旧响应不能重新打开或污染关闭后的状态。版本加载中关闭后在退场完成时清理 loading，保证详情里的版本入口可重新打开。详情开图和固定版本开图均等退场完成后导航。
6. 加入自选使用同步防重复提交保护，添加期间阻止返回/关闭；失败保留选择，其他分组已关注不等于当前分组已添加。
