# 原生 Header 迭代记录

方向依据见 direction-approved.md。形态来自交易图表的操作密度：把周期收藏放在最高优先级，图表库负责原生交互。

## 第一轮：直接开启原生 Header

截图检查发现：原生品种搜索重复标题、占用收藏空间；单图仍显示布局切换；原生折叠绘图入口只有 9px 宽。

处理：手机禁用 Header 品种搜索和布局切换，品种仍可点图例切换；使用公开 createButton 和 drawingToolbarAction，在 Header 中加入“绘图”入口，直接打开真实的绘图／光标工具栏；不搬动许可库 DOM。

## 第二轮：窄屏、收藏和返回

核对 375/412px 的深浅主题、14/21px 外层根字号和横屏截图。常用周期 M5/H1 初始展示，用户可加星及取消，收藏优先使用本机保存值。取消 H1 后重载不会重新添加。指标、设置、绘图均可触达。旧外层标题／自制周期控件／更多抽屉完整移除。

原生手机周期面板没有 dialog role；将实际 data-role=menuitem 纳入返回识别。返回先关闭周期／光标菜单，不直接退出图表。参数编辑仍遵循原有丢弃确认。

## 第三轮：实际部署触摸依赖

Ubuntu 首轮真实验证发现供应商原始压缩包缺少 floating-toolbars 引用的 Hammer 导出模块，底层 Hammer 包实际存在。通过构建 staging 中的 native-touch-assets.mjs 生成项目自有模块桥，校验两个原生输入 SHA256；不改许可源文件。把桥的内容计入库目录版本，避免缓存旧 404。新增浏览器验证实际 HTTP 加载两个触摸 chunk，并创建／释放原生 Hammer Manager。

最终截图见本目录。行情与蜡烛随请求变化，仅比较控件、布局与触达性。根字号检查不能替代 Android 系统字号和真机触摸验收。
