## 接入所需信息

每个平台记录设备型号、系统版本、浏览器版本、USB 或远程调试方式及操作人。
Android USB 接入 Ubuntu 且 adb 可用时，先核实明确的设备序列号，再只转发本任务端口：

```bash
adb devices -l
adb -s SERIAL reverse tcp:19997 tcp:19997
adb -s SERIAL reverse tcp:19998 tcp:19998
```

随后在该设备 Chrome 打开上述应用地址，并核实 iframe、登录和行情加载。
结束后仅移除这两个已创建的转发：

```bash
adb -s SERIAL reverse --remove tcp:19997
adb -s SERIAL reverse --remove tcp:19998
```

当前 Ubuntu 尚未安装 adb，也没有连接的 Android 设备；以上命令尚未执行。
iOS 需提供可用的 Safari 实机检查连接及应用/图表源访问方式；明确连接后再配置本任务入口并验证。
