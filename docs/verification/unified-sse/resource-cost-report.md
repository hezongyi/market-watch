## 稳定 managed 行情：相同输入的 60 秒对照

首屏历史和其他浏览器有效消费者退出后才采样；单周期每 5 秒一次、10 次输入，
八周期每 12 秒一批、4 批共 32 次输入。周期含 W1/MN。SSE 原生回调逐值接受；
轮询允许合并中间价格，并验证最后新值实际交付，不能要求它逐报价回调。

| 单周期 SSE | 0.534 | 13.4% | 1278.1 | 0.069 | 181.6 | 1.22 |
| 单周期轮询回退 | 0.484 | 12.1% | 1287.3 | 0.024 | 181.6 | 0.41 |

八周期 SSE/回退工作集差约 141.5 MiB；单周期差为 -9.2 MiB，
不据此宣称省内存。样本顺序、预热、缓存及 allocator 留存会影响工作集。
多连接样本在真实 worker/API 重启复核后运行，worker 是重新启动后的约 114.5 MiB；
不能与重启前约 181 MiB 的单周期样本直接推导多连接内存增量。
多连接保持一个共享 bar task、两个有效 bar 消费者；两个页面均逐输入收到回调。

## 磁盘

60 秒样本之后四张 market_stream 表（含索引/TOAST）合计约 0.70–1.70 MiB，
经历大量复跑、删除和 vacuum 后会变化；这不是干净安装的净新增磁盘。
WAL 为上表的实际窗口生成量，包含其他 worker 和 fixture，不能直接外推每日磁盘增长。
当前 API 镜像逻辑大小 290.2 MiB、web 61.1 MiB、chart 99.9 MiB，
是完整镜像而非本改动新增字节；worker 复用同一个 API 镜像，不重复存一份镜像。
精确 inspect 的 worker/API 容器 writable layer 各 4096 bytes。
共享镜像层、构建缓存和数据库/WAL复用阻止用镜像逻辑大小之和计算物理净新增占用；
缺少相同旧版本的物理差分，因此目前不报告虚构的磁盘净增量。

## 适用范围

这组数据是小规模、短时、合成输入的工程成本证据；首次成本试跑残留旧 lease，
以及跨网关重启出现负累计计数的探针，只保留为探索记录，不用于上述结论。
稀疏内存采样可能漏过瞬时峰值，block IO 字段在本机可能不可用。
真实供应商验收已完成；长期生产容量和旧发布版本完全新增成本不能由本报告代替。
