交付：中断等待的简单 step loop；保留既有 `run(stop)` 的复杂 loop adapter；统一组停止、非预期返回/未处理异常失败传播、信号停止和资源 join。业务循环负责自己的可恢复错误、租约、节奏和实际成功水位，监督器不重复重试或造心跳。
