# 通知时间显示与输入规则

已确认并实施于当前通知分支；复用现有 Ubuntu 验收项目。增量分类 F0：展示/输入和登录入口改动，不涉及 schema、时间戳格式、告警判定、确认或队列规则。整体通知 PR 的既有 F1/R2 分类保留。

- API、历史记录、告警到期值始终是 UTC Unix 毫秒。显示不回写记录。
- 图表桥接层统一发布激活图表时区，订阅 activeChartChanged、各图格 timezone 和 symbol 变化。多图采用当前激活图格。`exchange` 使用该品种数据源提供给图表的实际时区；待解析、初始化和异常回退显式标注 UTC。
- 原生通知中心、告警/日志、详情/异常发生记录、投递记录、即时浮窗及备用界面订阅同一来源；父页通过已校验来源与会话的桥接通道接收时区。不使用浏览器默认时区。
- 列表日期分组、事件/检测/观察时间随时区实时变化。详情带事件当时的 UTC 偏移，纽约 DST 两个同名时刻可对照。排查用原始 JSON 保留 UTC 毫秒；服务端生成消息中的发生时间仅在展示时转换。
- 筛选和到期输入按当前图表时区转换成 UTC 毫秒。已提交的筛选范围/到期时刻在切换时区时保持实际时刻，只转换输入框文字。范围是 `[since, until)`，整日通过该时区当日零点至次日零点选择，不固定加 24 小时。
- DST 跳跃中不存在的时间阻止查询/提交；重复时间用原生按钮选择第一次/第二次，标注偏移。已存时间可明确回读。到期的“不限/1 天/1 周/1 月”预设保持原有绝对时长语义，预设可清除尚未提交的无效输入。
- 本机超期缺失警示保留条数，不再嵌入无法随图表转换的浏览器本地时间；旧警示的该后缀仅在显示时省略，不迁移 IndexedDB 格式。
- `api.date` 不修改，避免影响其他页面。NativeSystemMessages / NativeInstantNotice 复用的子组件直接订阅时区，不增加另一套推断逻辑。

登录页同时接入已确认的最终 `ParticlesLogin`/`Particles` 组件，删除旧取模布点与 dot 样式。MIT 声明随正式 Web 镜像提供。认证回调、CSRF、密码处理和 next 跳转保持既有实现。

验收和明确边界见 [执行记录](verification/chart-timezone-20261019/README.md)。不合并、不发布生产。
