# Yahoo 原生高周期来源时间与显示标签边界

状态：待独立调查；由 OANDA REST/Swing 边界复核发现，不属于 PR #72 的修复范围。

Yahoo 悉尼市场的当前日柱可能具有晚于当前 UTC 时刻的日期标签。若普通价格入口以 UTC now 裁剪 chart_time，会遗漏已经发生的来源观察。需要按 Yahoo 各交易所的实际日历、时间戳含义与交易时区建立独立红绿回归；不得套用 OANDA NY17 的周期推导。

验收应分别覆盖来源时间截止、当前合法日期标签、显式历史分页、价格与指标快照一致性，以及 DST/交易日边界。Binance 和 Dukascopy 在本轮反例复核中未发现同类来源/日期标签差异；这不替代各自完整验收。
