已发现并处理：
- 编辑丢失响应后的再次核查先回读完整配置与版本，不先用旧版本 POST 制造假冲突。
- 到期结算不再提前被终态遮蔽；结算结束前不提供编辑/恢复。
- 最近触发通知独立于执行异常通知，规则结束后仍可见推送失败；读取详情/保存/暂停不清空最近触发时间。
- 触发详情独立刷新真实投递与设备回执；处理必须回读确认，受阻投递可沿用后端接口重试。
- 能力核验有界超时、就地重试；规则读取断网取消、健康与规则分别检查新鲜度；归档错误使用正确重试入口。
