# 双数据系列使用说明

2026-10-02。v1.3.0已完成Ubuntu本机交付，没有部署生产。运行镜像、验收及回退见 `chart-dual-dataset-local-delivery.md`。

## 选择行情

搜索同一品种会显示“平台行情”和“自建行情”，默认平台。平台从OANDA或Binance读取所选原生周期，九周期均支持，并保存独立平台缓存；不会写入自建行情或授权自建历史维护。两个系列的OHLC可能不同。原有工作区保持自建身份，不会后台换成平台。

桌面支持最多八图；比较品种、Python指标和CSV保留各自系列。预警与演练继续使用自建行情，不能将平台ticker提交给它们。

## 自建持续维护

首次选择尚未维护的自建品种时，可拒绝维护，图表保持空白；不会创建下载任务。要加入维护，使用“维护历史”，只填写历史补数起点。外汇/黄金日期按纽约17点交易日、比特币按UTC零点解释，表单显示该口径。

确认后从最近已完成分钟向过去分段回填，并持续维护后续行情。关闭页面、完成历史下载或取消历史回填均不停止实时维护。更早起点必须再次明确提交；缩放、翻页、周/月线或指标不会自动提前起点。拒绝维护不会自动切换行情系列。

各周期独立开放：正常需要三屏连续、完整、已发布的K线，屏容量按实际绘图区宽度除以柱间距向上取整。960px、6px的M5图需要480根完整K线。形成中K线不计入门槛，M5无需等待月线生成。若已经补齐批准起点，实际历史不足三屏也允许查看真实已有K线；没有完整K线或指标历史不足会在任务详情说明。

首次维护和历史完成时间不作承诺。查看“历史任务”可见批准起点、倒序游标、各周期完整根数/范围、初始化水位、实时水位以及下载/聚合失败和重试状态。下载或聚合失败不会替换此前已发布数据。

## 新历史与实时更新

已打开图表的历史左边界在本次会话内保持不变。后台完成更早段后，用“刷新历史”明确载入新范围，保留柱宽和查看位置。最新已发布K线通过实时订阅自动推进，无需手动刷新。忙碌时刷新会提示稍后操作，原有订阅继续运行。

周/月线只能使用批准起点后的完整覆盖派生；历史起点截断的桶不输出，不为凑桶自动越界补数。当前形成中的桶须有完整前缀覆盖，收盘且覆盖完成后才计为完整。上游最早M1之后才能提交有效起点，不可达起点会明确报错，不能当作成功。

## 保存、画线和手机

同一工作区、同品种、同系列跨周期共享画线；平台与自建画线永久隔离，没有复制入口；不同工作区也隔离。保存重开保留系列、周期、比较、轴模式、画线和视区。手机是临时单图只读，切换或缩放不会写回桌面文档。

日期同步对齐的是日期窗口，原生库可能按不同交易日历重新拟合柱间距；独立视区模式可保留各图自己的柱宽。绘图区不展示应用补数/根数进度或无数据占位，任务状态在主动打开的任务界面查看；真实错误和维护确认仍明确提示。

## 性能和既有边界

平台按用户最新门槛验收：大多数冷首屏低于3秒，代理/TLS或上游响应波动仍可能更慢；完整且足够新鲜的数据库缓存请求到显示低于1秒。前台按原生请求根数和Python指标需求返回，后台先准备基本窗口再补4000根深度缓存。平台缓存独立持久化到PostgreSQL，活跃周期由后端通过SSE更新；关闭图表后临时服务到期停止，自建持续维护规则不变。实测条件和长尾保留在[实施与验证记录](chart-dual-dataset-implementation.md)，不承诺每次或任意网络环境的耗时。平台失败走错误/重试，不将限流或网络失败冒充历史结束。

报价约15秒检查，平台报价来自提供商M1；自建报价来自本地M1。这里只提供现有价格口径，不伪造ask、点差、成交量、盘口或新闻。原生内置指标与Python指标可用，但CSV不包含原生内置指标值。原生包的导出及样式保存缺件仍使用顶部CSV和“保存样式”替代入口；不执行Pine、不接交易或图上预警。

本机候选入口为`https://localhost:15453/advanced-charts`，图表来源为`https://127.0.0.1:15454`，通知关闭。旧15443验收项目仍独立保留。源码、截图和测试证据均不等于生产发布。
