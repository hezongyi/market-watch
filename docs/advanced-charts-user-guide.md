# 专业图表使用与限制

更新：2026-09-30。本说明反映v1.2.0本地交付版本，不代表已经部署Unraid生产。逐项证据见[当前交付核对](advanced-charts-current-acceptance.md)。

2026-10-01正在开发双系列候选；当前候选的行情选择、维护、周/月线与画线隔离规则见[双数据系列使用说明](chart-dual-dataset-user-guide.md)。以下保留为v1.2.0历史说明，其冲突的自动补数规则不适用于双系列候选。

## 日常操作

| 操作 | 使用方式与保存规则 |
|---|---|
| 图表工作区 | 使用原生保存/加载入口；工作区可命名、复制、改名、删除。桌面自动保存，切换或供数繁忙时等待就绪后保存 |
| 多图 | 桌面最多八图；各图品种、周期独立；时间与视区默认同步，可关闭。不同品种不共享价格坐标 |
| 画线 | 同工作区同品种跨周期共享；不同工作区独立。绘图属性的可见范围控制在哪些周期显示 |
| 指标模板 | 保存指标组合与参数，跨工作区共用；删除模板不会删除已应用指标 |
| 绘图模板 | 保存工具样式；跨工作区共用，同名不同工具相互独立；应用模板不移动画线坐标 |
| 图表样式 | 顶部“保存样式”保存，同名覆盖；原生“设置 → 模板”应用或删除 |
| 收藏与偏好 | 周期、指标、绘图收藏及个人设置存到服务器，供工作区共用 |
| 图片 | 原生“生成快照 → 下载图片”；四图/八图与深浅主题已验证，导出保留库原生标识 |
| CSV | 顶部“导出 CSV”；包含行情及所选Python指标，**不包含原生内置指标值** |
| 手机 | 默认单图；临时切换品种、周期、缩放不写回桌面工作区及共用偏好。手机不提供完整绘图编辑 |

## 行情与时间

- Datafeed是图表访问行情的协议适配层。持久化、历史补数、分桶和任务队列由market-watch后台完成。
- 当前沿用M1行情更新，不是逐笔推送；显示的最后价格不代表每一笔成交。
- 外汇/黄金采用纽约17:00交易日边界，随纽约夏令时变化；比特币采用UTC00:00。图表显示时区只改变时间显示，不重新聚合OHLC。
- W1、MN由日线聚合。D1及以下优先；W1不足时排入低优先级后台队列，界面提示尚未就绪；无法可靠估算时明确显示“预计耗时暂无法估算”。
- MN只使用本地已有数据，不因误点月线启动大范围专门补数。因此月线历史较短或为空，不等于源头没有历史数据。
- 支持周期为 M1/M5/M15/M30/H1/H4/D1/W1/MN；秒级、逐笔及其他自定义周期未接入，原生输入入口存在不等于后台支持。
- 本地已覆盖区间直接读取；未覆盖区间按需排队拉取，速度取决于上游、代理、队列和聚合开销，不承诺固定完成时间。
- 向左拖动可能触发按需补数。正在加载、补数失败和已确认的历史边界是不同状态；失败可按提示重试，不能据此认定历史已经到头。
- 图表类型转换（如平均K线、砖形图）的价格含义不同于原始OHLC，不能把转换后的图形价格等同于原预警策略输入。

## 日线日期与显示时区示例

| 品种与口径 | 后台日桶示例（UTC） | 图表日线日期 |
|---|---|---|
| 黄金/外汇，纽约冬令时17点 | 2026-03-05 22:00 → 03-06 22:00 | 2026-03-06 |
| 黄金/外汇，纽约夏令时17点 | 2026-03-08 21:00 → 03-09 21:00 | 2026-03-09 |
| 比特币，UTC零点 | 2026-03-08 00:00 → 03-09 00:00 | 2026-03-08 |

日线传给原生库的午夜时间戳用于标记交易日期，不是该品种实际开盘时刻。日内K线保留真实桶起始时刻，切换显示时区改变时间文字；后台分桶、OHLC和策略判断不随图表显示时区改变。完整休市和缺数分别处理，缩短交易日不会被当作普通缺数自动填补。

## 旧工作区与删除规则

早期Advanced Charts保存的原始快照和当前原生包装格式均通过适配加载，包装转换保留画线坐标与样式。原来的轻量图表工作区继续独立保存；不同图表引擎的画线不做自动转换。

画线由原生工作区快照保存；删除后保存、刷新或切换周期不会重新出现。工作区删除另有版本检查和当前会话删除记录，防止旧列表响应或迟到保存把已删除工作区重新带回。冲突时应按提示重载或另存副本。

## 自选报价口径

- 最新价取本地最新M1收盘价。外汇、黄金采用bid口径；比特币按数据源成交价口径。这里不是可立即成交的买卖双边报价。
- bid行情只提供bid，不根据收盘价推算ask或点差。没有本地行情的品种返回“暂无本地报价”，不补0价格。
- 涨跌额、涨跌幅与完整且无交易时段缺口的前一交易日收盘价比较；参考日线缺失、参考价格为0或间隔不可确认时不提供这些字段。
- 描述包含行情口径、M1、UTC更新时间。距离M1结束不超过三分钟标记“最近更新”；超过阈值且按日历开市时标记“报价待更新”，休市时标记“按日历休市，最后报价”。这不是交易所实时交易状态认证。
- 自选与报价详情使用同一报价协议。没有成交量、市值、盘口等数据时不伪造字段；原生组件决定空字段的具体占位显示。

## 指标与额外数据

| 能力 | 当前边界 |
|---|---|
| 内置指标 | 由库读取图表数据计算；原生参数、样式与模板可用。这里没有Pine Script编辑器或运行环境，不能直接粘贴Pine代码运行 |
| Python指标 | 后台插件计算，通过适配器呈现；维护方法见[Python指标维护](python-chart-indicator-maintenance.md)。当前八类为SMA、EMA、LWMA、BBANDS、RSI、MACD、ATR、STOCH |
| 成交量指标、成交量蜡烛及成交量分布 | 当前主行情未提供volume输入，不能作为已支持功能；没有用零或tick数冒充真实成交量 |
| 深度、盘口、新闻与经济事件标记 | 未接入对应数据服务；库的接口或入口不会自动提供这些内容 |
| 多空盈亏比工具 | 属于画线分析工具，可标记入场/止损/止盈；不代表已连接交易账户或能发送订单 |
| 交易执行、图上预警、交互回放和策略回测 | 本次图表接入范围外；既有market-watch监控/演练模块独立，图表指标不会自动成为其策略 |

## 绘图工具分类

桌面保留原生绘图工具栏。以下按当前授权包的公开工具类型清单分类；“库提供”不代表每个工具都已逐项验收。工具的点数、快捷键与操作方式沿用原生库。

| 类别 | 库提供的主要工具 | 当前接入与依赖 |
|---|---|---|
| 线与通道 | 水平/垂直/十字线、趋势线、射线、延长线、平行通道、回归趋势 | 复用原生绘制和工作区保存；首版要求的水平线、趋势线、射线、平行通道已有专项 |
| 斐波那契与江恩 | 回撤、扩展、时间区、扇形、弧线、圆、螺旋、通道、江恩箱/扇 | 无新增外部数据服务；回撤已有专项，其余沿用库能力，未逐项核验几何算法 |
| 分叉线 | 标准/Schiff/修正Schiff/内部叉、扇形叉 | 原生坐标绘图，使用同一保存通路 |
| 形态与波浪 | XABCD、ABCD、Cypher、头肩、三角形、艾略特波浪 | 手工标注工具，不是自动识别形态或策略执行 |
| 几何与自由绘图 | 矩形、旋转矩形、圆、椭圆、三角形、折线、路径、曲线、画笔、高亮 | 原生绘图；矩形已有专项，其他类型不需要额外行情服务 |
| 文字与标记 | 文字、锚定文字、注释、便笺、标注框、箭头、价格标签、图标/表情 | 普通文字已有专项；图标、表情等仍取决于授权包对应资源是否齐备 |
| 测量与预测标注 | 日期范围、价格范围、日期价格范围、多空仓位、预测、柱形图形态、投影 | 多空盈亏比工具已有专项；均为分析标注，不会下单，不等于回测 |
| 成交量相关 | 锚定VWAP、固定范围成交量分布 | 当前供数缺少volume，不能列为可用分析能力；保留入口不代表已经接入 |

对象树、层级、锁定/隐藏、复制粘贴及模板继续使用原生功能。强吸附已通过真实鼠标端点与K线OHLC对照；不把此结果扩展为所有绘图工具或弱吸附阈值的完整验证。

## 原生缺件入口与替代方式

| 原生入口 | 当前处理 |
|---|---|
| 原生数据导出 | 包缺动态文件，原生入口不可用。请使用顶部“导出 CSV” |
| 图表样式模板的原生“保存为…” | 包缺保存对话框动态文件。请使用顶部“保存样式”；原生应用/删除可用 |
| 无公开禁用或点击拦截接口的入口 | 依用户要求保留；不能保证每个入口都能逐个置灰或弹出自定义提示。顶部“使用说明”提供统一指引，不修改供应库文件 |

桌面不再主动关闭交易账户管理、订单面板和经纪商入口；账户管理器可见，默认不主动展开，已保存的面板状态由原生库恢复。没有接入Broker适配器，因此账户管理器展开为空，不代表账户已连接；订单/经纪商按钮是否出现仍受原生库依赖控制。手机维持只读并关闭交易面板。交易终端本轮不接入，没有资金、持仓或下单通路。

## 验收与部署范围

当前验收运行在Ubuntu本机Docker，使用开发数据库，通知投递关闭。此状态不改变Unraid生产服务。本地Git提交、浏览器专项和截图证据不等于公网发布或全量验收完成；完整验收范围以交付核对表为准。

### 多图同步遇到完全休市窗口

当BTC等全天交易品种定位到周末，而黄金或外汇在目标窗口完全休市时，休市图定位至休市前最近交易窗口；顶部明确列出品种及目标UTC时间，并提示“目标区间休市，当前显示休市前行情”。原生库压缩休市时间轴，不生成虚假的休市K线。回到共同交易时段后恢复时间范围同步并清除提示；关闭同步也清除提示。休市由后台交易日历判定，不以历史数据缺失作为休市依据。

### 比较品种与价格轴

原生比较图支持独立价格轴及百分比显示，并随工作区保存。跨品种比较时，应分别查看对应价格轴；不同交易时段的比较线可能跨越休市区间连接前后交易点。这种连线不表示休市期间有成交或新增K线，也不改变后台预警所用的原始行情。
